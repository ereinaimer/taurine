# Taurine

Fast, secure and easy to use text expander and keyboard automation tool.

## Architecture

This project is organized into the following components:

- `core`: The core logic library.
- `cli`: The binary executable featuring the CLI.
- `daemon`: The background daemon logic.
- `tui`: The TUI interface.
