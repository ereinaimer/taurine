## Trigger Types

Taurine supports two ways to trigger an automation:

1. **Word Triggers**: Typed words preceded by a trigger character (e.g., `>brb`).
2. **Hotkey Triggers**: Global keyboard shortcuts (e.g., `ctrl+shift+g`).

## Adding Automations

### Word Triggers (Default)

To create a new text expansion triggered by a typed word, use the `add` or `set` command:

```bash
taurine add brb "Be right back"
```

If you add a trigger that already exists, Taurine will automatically update it with the new content.

### Hotkey Triggers

To create an automation triggered by a keyboard shortcut, use the `--hotkey` flag:

```bash
taurine add --hotkey "ctrl+shift+g" "git status[key.enter]"
```

For more details on hotkey syntax and validation, see the [Hotkey Triggers](/docs/cli/hotkey-triggers) page.

### Multi-OS Support
You can restrict automations to specific operating systems, or make them universal:

```bash
taurine add sig "Sent from Taurine" --os all      # Works everywhere
taurine add sig "Sent from Windows" --os windows  # Windows only
```

### Tagging Snippets
You can organize your automations using tags. Add tags using the `--tag` flag when adding a word trigger, hotkey trigger, or script:

```bash
taurine add gm "Good morning!" --tag work,email
taurine add brb "Be right back" --tag casual --tag priority
```

You can specify the `--tag` option multiple times or pass a comma-separated list of tags.

## How to Trigger

### Word Triggers
By default, Taurine triggers a word expansion when you type your **trigger character** followed by the **word** and a **space**.

```text
>brb[Space]
```

<Callout title="Configuring Triggers" type="info">
  You can change the default `>` trigger character in the [Configuration](/docs/cli/configuration) page.
</Callout>

### Hotkey Triggers
Hotkey triggers execute immediately when the keyboard shortcut is pressed. They do not require a trigger character or a trailing space.

## Inline Trigger Assist

Taurine provides a headless **inline trigger assist** to help you quickly find and select your word triggers as you type. This feature works directly inside your active text field—no popups, overlays, or command palettes are required. It includes both **Tab completion** for matches and **Up/Down history navigation** for recently used triggers.

### Usage

1. Type your **trigger character** (default: `>`).
2. Type a few characters of a **word trigger** (optional for history).
3. Use the following keys to navigate:

| Key | Action |
| :--- | :--- |
| **Tab** | Cycle forward through matching word triggers. |
| **Shift + Tab** | Cycle backward through matching word triggers. |
| **Up Arrow** | Move backward through recently used triggers (History). |
| **Down Arrow** | Move forward through history. |

### Tab Completion

After typing at least one character of a trigger (e.g., `>g`), press `Tab` to cycle through all triggers that start with that prefix. Suggestions are sorted alphabetically.

* **Wraparound**: Cycling is infinite; reaching the end of the list wraps back to the beginning.
* **Word Triggers Only**: Completion only suggests word triggers. Hotkey triggers are never suggested.

### History Navigation

History allows you to access your most frequently and recently used triggers.

* **Prefix Search**: If you type a prefix (e.g., `>g`) and press `Up`, Taurine cycles through recently used triggers starting with `g`.
* **Global History**: Pressing `Up` immediately after the trigger character (`>`) cycles through your entire trigger history.
* **Restore Query**: Pressing `Down` while the newest history item is selected will restore your original typed query.

### Control Keys

While assist is active, Taurine manages several keys to ensure a smooth experience:

* **Esc**: Cancels assist and leaves your typed text as-is.
* **Backspace**: Edits your **original query**. If you have a suggestion selected, Backspace erases the suggestion and deletes the last character of your typed input, allowing you to refine your search instantly.
* **Space**: Expands the currently visible trigger.
* **Modified Tabs**: Shortcuts like `Alt + Tab` or `Ctrl + Tab` will cancel assist and pass through to the system normally.

<Callout title="AI Mode Priority" type="info">
  Inline trigger assist is automatically disabled when you are in **Interactive AI Capture** mode. This ensures that arrow keys and Tab function normally while you are drafting a prompt for the AI.
</Callout>

<Callout title="Word Triggers Only" type="info">
  Trigger assist only suggests **word triggers**. Hotkey triggers are not included because they are triggered by global shortcuts rather than typed text.
</Callout>

### Configuration

Both Tab completion and History navigation are enabled by default. If you prefer to disable either feature (e.g., to prevent conflicts with terminal shells or specific applications), you can do so using the CLI:

```bash
# Disable Tab completion
taurine config set inline_tab_completion false

# Disable History navigation
taurine config set inline_history false
```

When disabled, the relevant keys (`Tab`, `Up`, `Down`) are passed through to the system normally. Disabling these assist features does not affect your ability to expand word triggers using `Space` or use the inline AI copilot.

## Viewing Your Automations

List all configured automations with `taurine list` (alias: `ls`). You can sort them to find your most used snippets:

```bash
taurine list --sort usage --desc  # See your most used triggers first
taurine ls --sort recent          # Alias 'ls' also works
```

### Filtering by Tag
You can filter listed automations to only show those that have a specific tag:

```bash
taurine list --tag work
```

## Deleting Automations

Remove one or more triggers using the `rm` command (aliases: `remove`, `delete`):

```bash
taurine rm brb gm sig
taurine delete obsolete_trigger
```

### Deleting by Tag
You can remove all automations that have a specific tag by using the `--tag` flag:

```bash
taurine delete --tag obsolete_trigger
```
