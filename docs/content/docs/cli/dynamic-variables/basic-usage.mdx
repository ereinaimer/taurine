Dynamic variables are the secret sauce that makes your Taurine snippets truly flexible. Instead of static text, they allow you to create templates that react to the context of your input—turning simple macros into powerful automation tools.

The core of the system is the square bracket syntax: `[variable_name]`. 

### Escaping Brackets
If you want to use literal square brackets without treating the inner text as a variable, escape them with a backslash: `\[name\]`. 

This is useful when writing code snippets or documentation where you want the brackets to remain visible in the expanded text instead of being replaced.

When Taurine encounters a bracketed word, it converts it into an **input mapping**. Anything you type after the colon (`:`) in your trigger is captured and injected directly into that placeholder at the moment of expansion.

### Basic Mapping
If your snippet has a single variable, Taurine maps the entirety of your terminal argument to that specific placeholder.

<Transformation
  template="Hello, [name]!"
  input=">hello:Erein"
  result="Hello, Erein!"
/>

### Multi-Variable Snippets
You aren't limited to just one variable. You can scatter placeholders throughout your text to build sophisticated templates.

<Transformation
  template="GRANT ACCESS TO [user] ON [environment]"
  input=">access:admin:staging"
  result="GRANT ACCESS TO admin ON staging"
/>

By adding more colons to your trigger, you can pipe multiple arguments into your snippet in one go.
