---
title: Basic Variables
description: Use dynamic placeholders to drop values directly into your text.
---

Dynamic variables make your Taurine snippets truly flexible. Instead of static text, they allow you to create templates that react to the context of your input—turning simple macros into powerful trigger tools.

The core syntax uses square brackets with a leading `$` symbol and a mandatory `=` to declare the variable and its fallback value: `[$variable_name = "default"]`.

Once declared, a variable can be re-used anywhere in the template without re-specifying the default: `[$variable_name]`.

### Escaping Brackets
If you need a literal square bracket in your output that is **not** a variable at all, prefix it with a backslash: `\[` outputs `[`, and `\]` outputs `]`.

```text
Result: \[0\] + 1 = [$value = "1"]
→ Result: [0] + 1 = 1
```

When Taurine encounters a bracketed dynamic variable, it converts it into an **input mapping**. Anything you type after the semicolon (`;`) in your trigger is captured and injected directly into that placeholder at the moment of expansion.

### Basic Mapping
If your snippet has a single variable, Taurine maps your terminal argument to that specific placeholder.

<Transformation
  template='Hello, [$name = "stranger"]!'
  input="hello;Erein"
  result="Hello, Erein!"
/>

### Multi-Variable Snippets
You aren't limited to just one variable. You can scatter placeholders throughout your text to build sophisticated templates.

<Transformation
  template='GRANT ACCESS TO [$user = "guest"] ON [$environment = "sandbox"]'
  input="access;admin;staging"
  result="GRANT ACCESS TO admin ON staging"
/>

By adding more semicolons to your trigger, you can supply multiple arguments into your snippet in one go.
