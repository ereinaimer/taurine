description: Overview of Dynamic Variables in Taurine
---

Dynamic variables allow you to insert user input, arguments, and transformations directly into your text snippets. 
They let you create sophisticated templates that adapt based on the inputs you provide when triggering them.

This section covers:
- **Basic Usage**: Simple placeholders for user data.
- **Default Values**: Fallbacks for omitted arguments.
- **Arguments**: Using positional and named inputs.
- **Transformers**: Changing the casing and formatting of your text on the fly.

Navigate through this section using the sidebar to learn how to unlock the full power of Taurine's variable engine!
