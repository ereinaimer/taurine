## Using Transformers

Taurine can apply text transformers directly to your arguments before expansion. Use the dot notation `.modifier` next to your variable tag.

### Available Transformers

```text
[name.upper]       -> UPPERCASE
[name.lower]       -> lowercase
[name.title]       -> Title Case
[name.snake]       -> snake_case
[name.kebab]       -> kebab-case
[name.pascal]      -> PascalCase
[name.camel]       -> camelCase
[name.shoutysnake] -> SHOUTY_SNAKE
[name.shoutykebab] -> SHOUTY-KEBAB
[name.train]       -> Train-Case
[name.urlencode]   -> hello%20world
```
