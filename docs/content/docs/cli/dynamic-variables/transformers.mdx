## Using Transformers

Taurine can apply text transformers directly to your arguments before expansion. Use the dot notation `.modifier` next to your variable tag.

### Available Transformers

```text trigger=">format:'hello world from taurine' "
Upper: [0.upper]
Camel: [0.camel]
URL: [0.urlencode]
```

<Callout title="Keep it flat" type="info">
  Prefer flat forms like `[query.urlencode]`. While some nested transformers might resolve depending on string parsing, it's safer to keep them straightforward.
</Callout>
