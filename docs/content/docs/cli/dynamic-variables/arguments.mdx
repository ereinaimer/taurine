---
title: Arguments
description: Fill named fields inline with bare or labeled values.
---

## Bare Values Fill in Order

Write one template with named fields, then fill values inline separated by semicolons (`;`). Bare values fill named fields in template definition order.

<Transformation
  template='Meet at [$time = "now"] in [$place = "here"]'
  input="meet;2pm;the lobby"
  result="Meet at 2pm in the lobby"
/>

## Named Arguments

Explicitly assign a value to a label using the `key=value` format when typing your trigger. Explicit names always win regardless of position, and matching is case-insensitive.

<Transformation
  template='Repo: [$repo = "default_repo"] by [$name = "default_name"]'
  input="gh;name=ereinaimer;repo=nite"
  result="Repo: nite by ereinaimer"
/>

Named arguments override position. Even though `name` was typed first, it correctly filled the `[$name = "default_name"]` placeholder.

## Quoted Arguments

Quotes allow arguments to contain spaces or semicolons without breaking the trigger parsing. Nite supports both double quotes (`"`) and single quotes (`'`).

<Transformation
  template='Quote: [$message = "empty"]'
  cases={[
    { input: "quote;'\"One small step for man\"'", result: 'Quote: "One small step for man"' },
    { input: "quote;\"How're you?\"", result: "Quote: How're you?" },
  ]}
/>

## Ordered Fallback & Skipping

Bare values fill named fields in the order the fields appear in the template, skipping fields already satisfied by an explicit `key=value`. Missing values use their defaults. An empty segment (`;;`) keeps the default value, allowing you to skip a placeholder.

<Transformation
  template='Repo: [$repo = "nite"] / User: [$user = "erein"]'
  input="gh;;aimer"
  result="Repo: nite / User: aimer"
/>
