Taurine's **Inline AI Copilot** brings powerful Large Language Models directly to your cursor. Whether you need to rewrite a sentence, generate a function, or brainstorm ideas, you can trigger AI assistance without leaving your active window.

## Add An AI Provider

Taurine supports a vast range of top-tier AI providers, including specialized platforms for performance and low latency

```bash
taurine ai add --provider <name>
```

### Provider Management
- **List providers**: `taurine ai list`
- **List models**: `taurine ai models --provider <name>`
- **Remove provider**: `taurine ai remove --provider <name>`

## Usage

Taurine operates inline anywhere you can type. There are no special delimiters, modal states, or capture modes to remember. Simply use the natural prefix **`tau,`** followed by your prompt, and hit **Enter**:

```text
tau, what is the capital of France?[Enter]
```

Or for code generation:

```text
tau, write a rust function to parse json[Enter]
```

### Prefix Requirements

To prevent conflicts with Taurine's CLI alias `tau`, the trailing comma is strictly required. Any case-insensitive variation of `tau,` is supported:

- `tau, <prompt>`
- `Tau, <prompt>`
- `TAu, <prompt>`
- `TAU, <prompt>`

<Callout title="Comma Required" type="warning">
  Taurine strictly requires the trailing comma (`tau,`). Prompts typed as `tau <prompt>` or `tau: <prompt>` will not trigger inline AI, ensuring that daily CLI usage like `tau add` or `tau config` in terminals is never intercepted.
</Callout>

### Mid-Line Typing

You do not need to be at the beginning of a line to invoke AI assistance. If you are drafting a message or document:

```text
The team discussed the launch timeline. tau, summarize key risks[Enter]
```

Taurine precisely backspaces only the `tau, summarize key risks` portion, leaving `"The team discussed the launch timeline. "` completely intact, and streams the AI output directly after it.

### Empty Prompt Safety

If you type `tau` or `tau,` and press **Enter** without a prompt, Taurine treats it as standard typing and lets your Enter key pass straight through to the operating system.

## Configuration

### Enabling / Disabling Inline AI

Inline AI is enabled by default. You can toggle it at any time:

```bash
taurine config set inline_ai_enabled false
```

### Custom Endpoints

If you are using the `custom` provider (e.g., Local LLMs via Ollama or LM Studio), configure your endpoint:

```bash
taurine config set ai_custom_endpoint http://localhost:11434/v1
```

## Provider Selection

Taurine determines which provider to use based on your active configuration:

1. **Explicit Setting**: If `ai_provider` is set via `taurine config set ai_provider <name>`, that provider is always used.
2. **Auto-Selection**: If `ai_provider` is not set but you have exactly **one** provider configured (via `taurine ai add`), Taurine will use it automatically.
3. **Manual Conflict**: If multiple providers are configured but no default is set, Taurine will prompt you to set an `ai_provider` before it can execute a request.
