Taurine's **Inline AI Copilot** brings powerful Large Language Models directly to your cursor. Whether you need to rewrite a sentence, generate a function, or brainstorm ideas, you can trigger AI assistance without leaving your active window.

## Add An AI Provider

Taurine supports a vast range of top-tier AI providers, including specialized platforms for performance and low latency

```bash
taurine ai add --provider <name>
```

### Provider Management
- **List providers**: `taurine ai list`
- **List models**: `taurine ai models --provider <name>`
- **Remove provider**: `taurine ai remove --provider <name>`

## Usage Modes

Taurine provides multiple ways to interact with AI directly from your text area.

<Tabs items={['Quoted Prompt', 'Interactive Capture']}>
  <Tab value="Quoted Prompt">
    The fastest way for short instructions. Type your trigger, then the prompt in quotes:
    
    ```text
    >ai:'hello'
    >ai:"Rewrite this politely"
    ```
    This immediately starts the AI request and replaces the trigger with the response.
  </Tab>
  <Tab value="Interactive Capture">
    Best for longer prompts. Type `>ai` followed by a space to open the capture delimiter:
    
    ```text
    >ai
    ```
    Taurine inserts the opening delimiter (default: `` ` ``). Type your prompt, close the delimiter, and press `Space` again:
    
    ```text
    `write a haiku about rust`
    ```
  </Tab>
</Tabs>

## AI Presets

Presets allow you to save complex system instructions or specific personas under short aliases.

### Management
```bash
# Add a preset for simple explanations
taurine ai preset add eli5 "explain this like I'm five"

# Add a preset for code documentation
taurine ai preset add doc "generate rust documentation for the following code"
```

### Usage
Trigger any preset using the format `>ai.[alias]`:

```text
>ai.eli5 Space
```

## Advanced Configuration

### Custom Endpoints
If you are using the `custom` provider (e.g., Local LLMs via Ollama or LM Studio), set your endpoint:

```bash
taurine config set ai_custom_endpoint http://localhost:11434/v1
```

### Custom Delimiter
If the default backtick (`` ` ``) conflicts with your workflow, change the capture delimiter:

```bash
taurine config set inline_ai_delimiter ~
```

## Provider Selection

Taurine determines which provider to use based on your active configuration:

1. **Explicit Setting**: If `ai_provider` is set via `taurine config set ai_provider <name>`, that provider is always used.
2. **Auto-Selection**: If `ai_provider` is not set but you have exactly **one** provider configured (via `taurine ai add`), Taurine will use it automatically.
3. **Manual Conflict**: If multiple providers are configured but no default is set, Taurine will prompt you to set an `ai_provider` before it can execute a request.
