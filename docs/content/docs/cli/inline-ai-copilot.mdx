Taurine's **Inline AI Copilot** brings powerful Large Language Models directly to your cursor. Whether you need to rewrite a sentence, generate a function, or brainstorm ideas, you can trigger AI assistance without leaving your active window.

## Configuration Wizard

Launch the interactive AI configuration wizard from any terminal:

```bash
tau ai
```

### Interactive Hotkeys

| Key | Action |
| :--- | :--- |
| `j` / `k` | Navigate between configured providers |
| `n` | Add a new AI provider (Gemini, OpenAI, Claude, Groq, Ollama, etc.) |
| `Enter` | Set selected provider as active and edit model name |
| `d` | Remove provider credentials from OS keyring |
| `q` / `Esc` | Exit configuration wizard |

### Non-Interactive (Headless) Automation

For headless environments, automated setups, and scripts, pass the `-y` flag:

```bash
# Check active and configured providers
tau ai -y

# Output status in JSON format
tau ai -y --json

# Configure a provider
tau ai -y --provider gemini --key <YOUR_API_KEY>

# Configure a provider with a specific model
tau ai -y --provider openai --key <YOUR_API_KEY> --model gpt-4o

# Configure a custom local endpoint (e.g. Ollama or LM Studio)
tau ai -y --provider custom --endpoint http://localhost:11434/v1 --model llama3

# Remove a provider
tau ai -y --remove gemini

# Remove all configured providers
tau ai -y --remove-all
```

## Usage

Taurine operates inline anywhere you can type. There are no special delimiters, modal states, or capture modes to remember. Simply use the natural prefix **`tau,`** followed by your prompt, and hit **Enter**:

```text
tau, what is the capital of France?[Enter]
```

Or for code generation:

```text
tau, write a rust function to parse json[Enter]
```

### Prefix Requirements

To prevent conflicts with Taurine's CLI alias `tau`, the trailing comma is strictly required. Any case-insensitive variation of `tau,` is supported:

- `tau, <prompt>`
- `Tau, <prompt>`
- `TAu, <prompt>`
- `TAU, <prompt>`

<Callout title="Comma Required" type="warning">
  Taurine strictly requires the trailing comma (`tau,`). Prompts typed as `tau <prompt>` or `tau: <prompt>` will not trigger inline AI, ensuring that daily CLI usage like `tau add` or `tau config` in terminals is never intercepted.
</Callout>

### Mid-Line Typing

You do not need to be at the beginning of a line to invoke AI assistance. If you are drafting a message or document:

```text
The team discussed the launch timeline. tau, summarize key risks[Enter]
```

Taurine precisely backspaces only the `tau, summarize key risks` portion, leaving `"The team discussed the launch timeline. "` completely intact, and streams the AI output directly after it.

### Clipboard Context

You can provide copied text or code as context to your inline AI prompt in two seamless ways:

1. **Paste Shortcut (`Ctrl + V` / `Cmd + V`)**: When typing after a `tau,` prefix, pressing your paste shortcut automatically intercepts the paste, preventing large code or multi-line text from flooding your editor. Instead, Taurine types a compact placeholder token:
   - For multi-line text: `[clipboard: 34 lines]`
   - For single-line text: `[clipboard: 18 words]` (or `[clipboard: 1 word]`)
2. **Explicit Token (`[clip]`)**: You can also manually type `[clip]` anywhere inside your prompt:
   ```text
   tau, reformat this in json: [clip][Enter]
   ```

When you hit **Enter**, Taurine deletes only the concise single line on screen, substitutes the raw clipboard content directly into the prompt as-is, and streams the AI response directly into your active window.

<Callout title="Atomic Erasure & Chat Apps" type="info">
  By replacing large pastes with compact placeholder tokens, Taurine only needs to backspace a single line of text on Enter. This avoids the multi-line backspace lag and accidental message sends common when pasting raw multi-line text into chat applications like Slack or Discord.
</Callout>

### Empty Prompt Safety

If you type `tau` or `tau,` and press **Enter** without a prompt, Taurine treats it as standard typing and lets your Enter key pass straight through to the operating system.

## Configuration

### Enabling / Disabling Inline AI

Inline AI is enabled by default. You can toggle it at any time:

```bash
taurine config set inline_ai_enabled false
```

### Custom Endpoints

If you are using the `custom` provider (e.g., Local LLMs via Ollama or LM Studio), configure your endpoint:

```bash
taurine config set ai_custom_endpoint http://localhost:11434/v1
```

## Provider Selection

Taurine determines which provider to use based on your active configuration:

1. **Explicit Setting**: If `ai_provider` is set via `taurine config set ai_provider <name>`, that provider is always used.
2. **Auto-Selection**: If `ai_provider` is not set but you have exactly **one** provider configured (via `tau ai`), Taurine will use it automatically.
3. **Manual Conflict**: If multiple providers are configured but no default is set, Taurine will prompt you to set an `ai_provider` before it can execute a request.
