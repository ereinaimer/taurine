Taurine features a built-in unit conversion engine that lets you convert physical units and currencies directly as you type. Simply type a conversion pattern and press **Space** or **Enter** (depending on your configured Action Key).

For example, typing `100c=f ` will instantly expand to `212f`.

<Callout title="Instant Expand Conflict" type="warning">
  If **Instant Expand** mode is enabled, the Inline Unit Converter (as well as Inline Math, Inline Emojis, and Inline completions/history) is automatically disabled to prevent conflicts during real-time character processing.
</Callout>

## How It Works

Type a value followed by a unit, an equals sign `=`, and the target unit:
`<value><from_unit>=<to_unit>`

* **Example:** `100c=f`, `1.5gb=mb`, `-40c=f`, `32psi=bar`.
* **Case Insensitive:** Units are case-insensitive (`100C=F` works identically to `100c=f`).
* **Format:** The converted value is output with up to 2 decimal places by default (or up to 4 decimal places for values less than 0.01).

### Natural Language Conversions

Taurine also supports natural language unit and currency conversions. You can express conversions using common separators: `to`, `in`, `into`, or `as`.

* **Example:** `100 dollars to Euros`, `$100 to Euros`, `1.5 gigabytes to megabytes`, `32 celsius in fahrenheit`, `5 miles into kilometers`.
* **Casing & Spacing Preservation:** The converter respects the casing, spelling, and spacing style of your query. For example, `1.5 gigabytes to megabytes` outputs `1500 megabytes` (with a space and written-out unit), while `1.5gb=mb` outputs `1500mb` (compact syntax).
* **Triggerless Mode:** Conversions without a trigger prefix require **Triggerless Mode** to be enabled in settings (enabled by default).
* **Command Prefixes:** You can optionally prefix natural language conversions with command words like `convert`, `transform`, `change`, `calculate`, `compute`, `what is`, `what's`, or `how much is` — e.g. `convert 100 dollars to Euros`, `what is 32 celsius in fahrenheit`, `how much is 5 miles into km`.

### Color Formats
Convert colors between formats using either compact or natural language syntax:

| Input | Output |
|-------|--------|
| `#3b82f6=rgb` | `rgb(59, 130, 246)` |
| `#3b82f6 to hsl` | `hsl(217, 91%, 60%)` |
| `red to hex` | `#FF0000` |
| `rgb(59,130,246) to hex` | `#3B82F6` |

* **Supported formats:** `hex`, `rgb`, `rgba`, `hsl`, `hsla`.
* **Input formats:** Hex colors (`#ff0000`, `#fff`), CSS named colors (`red`, `blue`), or `rgb()`/`rgba()`/`hsl()`/`hsla()` strings.

## Dynamic Currency Conversions

Taurine can convert between any standard 3-letter ISO currency codes (e.g. `usd=eur`, `eur=inr`, `gbp=jpy`).

* **Dynamic Caching:** Taurine fetches real-time rates dynamically from a public API and caches them locally. To prevent UI delays, conversions are served instantly from the local cache. If the cache is older than 24 hours, a background thread updates it in the background.
* **Offline Fallback:** If you are offline and have no cache file, Taurine automatically falls back to built-in, approximate exchange rates for major currencies (USD, EUR, INR, GBP, JPY, CAD, AUD, CNY).
