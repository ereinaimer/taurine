This reference provides a comprehensive list of all commands, flags, and aliases available in the Taurine CLI.

## Global Flags

These flags can be used with any command to modify the CLI's behavior.

| Flag | Description |
| :--- | :--- |
| `-v, --verbose` | Increase console verbosity (can be used multiple times). |
| `-q, --quiet` | Disable all console logging output. |
| `--no-log-file` | Disable writing logs to the daily log file. |
| `--no-color` | Disable colorized output in the terminal. |

## Service Management

Commands for managing the Taurine background daemon.

<Accordions>
<Accordion title="up / start">
  Starts the Taurine background service.
  ```bash
  taurine up
  ```
</Accordion>

<Accordion title="down / stop">
  Stops the Taurine background service.
  ```bash
  taurine down
  ```
</Accordion>

<Accordion title="restart / reboot">
  Restarts the Taurine background service.
  ```bash
  taurine restart
  ```
</Accordion>

<Accordion title="status">
  Checks if the Taurine daemon is currently running.
  ```bash
  taurine status
  ```
</Accordion>
</Accordions>

## Automation Management

Commands for creating, viewing, and deleting your snippets and scripts.

<Accordions>
<Accordion title="add / set">
  Adds a new text or script automation.
  
  **Standard Text:**
  ```bash
  taurine add <trigger> <output> [--hotkey] [--os <target>]
  ```
  
  **Shell Script:**
  ```bash
  taurine add script <trigger> <body> [--hotkey] [-l <lang>] [-m <mode>]
  taurine add script <trigger> -f <path> [--hotkey]
  ```
  
  **Optional Flags:**
  - `--hotkey`: Interpret the trigger as a global keyboard shortcut instead of a word.
  - `-f, --file <path>`: Load script content from a file.
  - `-l, --lang <bash|powershell|python|node|node-esm|cmd>`: Specify the interpreter.
  - `-m, --mode <inline|silent>`: Choose execution mode.
  - `--os <windows|linux|macos|all|android|ios|current>`: Target specific platforms.
</Accordion>

<Accordion title="list / ls">
  Lists all active automations.
  ```bash
  taurine list [--sort <alpha|usage|created|recent>] [--asc|--desc] [--plain]
  ```
</Accordion>

<Accordion title="delete / rm / remove">
  Removes one or more automations by their trigger.
  ```bash
  taurine delete <trigger>...
  ```
</Accordion>
</Accordions>

## Data Exchange

Commands for backing up and restoring your Taurine environment.

<Accordions>
<Accordion title="export">
  Exports automations, settings, and stats to a encrypted or plaintext file.
  ```bash
  taurine export [path] [-p, --plain] [-s, --settings] [-t, --stats] [-x, --sensitive]
  ```
</Accordion>

<Accordion title="import">
  Imports data from a Taurine exchange file.
  ```bash
  taurine import <path> [--on-conflict <prompt|skip|overwrite>] [-s, --settings] [-t, --stats <ignore|merge|overwrite>] [-x, --sensitive]
  ```
</Accordion>
</Accordions>

## Configuration

Manage internal application settings.

<Accordions>
<Accordion title="config set">
  Sets a configuration value.
  ```bash
  taurine config set <key> <value>
  ```
</Accordion>

<Accordion title="config list / ls">
  Lists all current settings and their values.
  ```bash
  taurine config list
  ```
</Accordion>

<Accordion title="config reset">
  Resets a setting to factory defaults.
  ```bash
  taurine config reset <key>
  taurine config reset --all
  ```
</Accordion>
</Accordions>

## AI Copilot

Manage AI providers.

<Accordions>
<Accordion title="ai add">
  Adds a provider credential. You will be prompted for the API key.
  ```bash
  taurine ai add --provider <name>
  ```
</Accordion>

<Accordion title="ai models">
  Lists models supported by a specific provider.
  ```bash
  taurine ai models --provider <name>
  ```
</Accordion>

<Accordion title="ai list / ls">
  Lists all configured AI providers.
  ```bash
  taurine ai list
  ```
</Accordion>

<Accordion title="ai remove">
  Removes a provider's credentials from the OS keyring.
  ```bash
  taurine ai remove --provider <name>
  ```
</Accordion>

</Accordions>

## Shell Completions

Generate or install shell completion scripts.

<Accordions>
<Accordion title="Manual Generation">
  Prints the completion script for your shell to stdout.
  ```bash
  taurine completions <bash|elvish|fish|powershell|zsh>
  ```
</Accordion>

<Accordion title="Automatic Installation">
  Installs completions for your current shell and platform automatically.
  ```bash
  taurine completions install
  taurine completions uninstall
  ```
</Accordion>
</Accordions>
