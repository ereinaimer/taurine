---
title: System Limits
description: Understand Taurine's safety limits for snippet expansion and AI usage.
icon: ShieldAlert
---

Taurine is designed to give you maximum power and flexibility over your automation workflows. However, to protect your system from catastrophic resource exhaustion (like stack overflows) and to prevent accidental API bill spikes, Taurine enforces a few strict limits during snippet expansion.

These limits are enforced **when you save or update a snippet**, giving you instant feedback rather than failing silently at runtime.

### Nested Snippet Recursion Limit
You can compose snippets by nesting them using the `[use("trigger")]` system variable. To prevent infinite loops (e.g., Snippet A uses Snippet B, which uses Snippet A), Taurine limits the maximum recursion depth.

*   **Max Depth:** 5 nested levels.
*   **What happens if exceeded:** The snippet will fail to save with a `Max recursion depth reached` error.

### AI Transformer Limits
The `| ai(...)` transformer makes live requests to external Large Language Models (like OpenAI or Anthropic). Since these requests cost money and hit rate-limits, Taurine prevents runaway API usage caused by deep nesting.

*   **Max AI Calls:** 3 total calls per fully-expanded snippet sequence.
*   **What happens if exceeded:** If a snippet (including all its nested `[use(...)]` children) contains more than 3 AI transformers, it will fail to save with an `exceeds the limit of 3` error.

### What is NOT Limited
True to the Unix philosophy, lightweight operations are completely unrestricted:

*   **Standard Variables:** You can use as many lightweight system variables (`[time]`, `[clip]`, `[uuid]`, etc.) as you want.
*   **Modifier Chains:** You can chain as many fast, in-memory modifiers as needed (e.g., `[clip | trim | upper | slug]`).
*   **Scripts and Network Calls:** Taurine intentionally does **not** limit HTTP requests or shell process executions. You have full power over your local environment.
