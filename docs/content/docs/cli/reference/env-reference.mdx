Taurine can be customized using environment variables. These variables allow you to redirect data storage paths, configure custom authentication tokens, and override default system behaviors.

## Taurine Specific Environment Variables

These environment variables are specific to Taurine's client and daemon processes.

<Accordions>
<Accordion title="TAURINE_RPC_TOKEN">
  Overrides the secret Bearer authorization token used to secure connection channels between the clients (TUI/CLI) and the background daemon across all modes (TCP, sockets, and named pipes).
  
  - **Type**: String (typically a UUID)
  - **Usage**: Set this variable in the environment of your client terminal or script to bypass the local database lookup.
  - **Example**:
    ```bash
    export TAURINE_RPC_TOKEN="your-secure-token-here"
    taurine reload
    ```
</Accordion>

<Accordion title="TAURINE_DATA_DIR">
  Overrides the default user data directory where Taurine stores configurations, logs, and sockets.
  
  - **Type**: Absolute Directory Path
  - **Default**: 
    - macOS: `~/Library/Application Support/com.ereinaimer.taurine`
    - Linux: `~/.config/taurine`
    - Windows: `%APPDATA%\com.ereinaimer.taurine`
  - **Example**:
    ```bash
    export TAURINE_DATA_DIR="/tmp/taurine-data"
    taurine up
    ```
</Accordion>

<Accordion title="TAURINE_DB_PATH">
  Overrides the path to the SQLite database file containing all snippets, triggers, and settings.
  
  - **Type**: Absolute File Path
  - **Default**: `<TAURINE_DATA_DIR>/taurine.db`
  - **Example**:
    ```bash
    export TAURINE_DB_PATH="/custom/path/to/my_macros.db"
    taurine up
    ```
</Accordion>
</Accordions>

## Standard System Environment Variables

Taurine also references several standard operating system environment variables to adapt to the current system environment.

| Variable | Operating System | Description |
| :--- | :--- | :--- |
| `HOME` | Linux / macOS | Used to locate the user's home directory. |
| `USERPROFILE` | Windows | Used to locate the user's home directory. |
| `SHELL` | Linux / macOS | Used to detect the active shell to automatically install shell completions and aliases. |
| `WAYLAND_DISPLAY` | Linux | Used to detect Wayland display servers to configure window/fullscreen focus tracking. |
| `DISPLAY` | Linux | Used to detect X11 display servers for fallback window focus tracking. |
