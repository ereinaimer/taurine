System variables in Taurine use the format `[root.modifier]`. This reference covers all available reserved roots and their associated modifiers.

## Variable Roots

The following roots are reserved by the Taurine engine and cannot be used as custom variable names.

| Root | Description |
| :--- | :--- |
| `time` | Current system time in various formats. |
| `date` | Current system date in various formats. |
| `clip` | Content of the system clipboard. |
| `cursor` | Directs the final cursor position (placeholder). |
| `uuid` | Unique identifier generation. |
| `env` | System environment variables. |
| `file` | Read local file contents. |
| `key` | Keyboard automation (simulating key presses). |
| `delay` | Timing delays in execution sequences. |

## Time & Date

Modifiers for inserting timestamps and relative dates.

<Accordions>
<Accordion title="time">
  - `greeting`: Inserts "Good morning", "Good afternoon", or "Good evening".
  - `unix` / `epoch`: Current Unix timestamp in seconds.
  - `utc`: Current time in UTC (HH:mm). For seconds, use `utc.full`.
  - `tz`: Current local timezone offset (e.g., `+05:30`).
  - `now`: Current time (HH:mm).
  - `full`: Current time with seconds (HH:mm:ss).
</Accordion>

<Accordion title="date">
  - `iso`: YYYY-MM-DD format.
  - `short`: MM/DD/YYYY.
  - `long`: Month name, Day, Year.
  - `tomorrow` / `yesterday`: Following/Previous day's date (**Default: ISO**).
  - `tomorrow.short` / `tomorrow.long`: Relative dates with specific formatting.
  - `weekday`: Full name of the current day.
  - `year` / `month` / `day`: Numeric components of the current date.
</Accordion>
</Accordions>

## Environment & Clipboard

Interact with your local system state and shell environment.

<Accordions>
<Accordion title="clip">
  - `[clip]`: The most recent clipboard item (same as `[clip(0)]`).
  - `[clip(0)]` / `[clip(1)]` / `[clip(2)]`: Indexed clipboard history (up to 3 entries).
</Accordion>

<Accordion title="env">
  Access any environment variable reachable by the Taurine daemon.
  - `[env(USER)]` / `[env(USERNAME)]`
  - `[env(PATH)]`
  - `[env(HOME)]` / `[env(USERPROFILE)]`
</Accordion>

<Accordion title="file">
  Read and inject local file contents natively.
  - `[file.read(path)]`: Reads the entire contents of a file (up to 5MB).
  - `[file.read_line(path, start, [end])]`: Extracts specific lines using a 1-indexed range.
</Accordion>
</Accordions>

## Automation & Identity

Modifiers for generating IDs or simulating hardware interaction.

<Accordions>
<Accordion title="uuid">
  - `[uuid.v4]`: Explicit version 4 UUID.
  - `[uuid.v7]`: Time-sorted version 7 UUID.
</Accordion>

<Accordion title="key">
  Simulate non-printing keys or keyboard combinations.
  - `[key(enter)]`, `[key(tab)]`, `[key(esc)]`, `[key(space)]`
  - `[key(up)]`, `[key(down)]`, `[key(left)]`, `[key(right)]`
  - `[key(ctrl+v)]`, `[key(alt+tab)]`, `[key(shift+p)]`
  - **See [Keyboard Automation](/docs/cli/system-variables/keyboard-automation) for a full list of aliases.**
</Accordion>

<Accordion title="delay">
  Pause execution for a specific duration (milliseconds).
  - `[delay(100ms)]` or `[delay(100)]`
</Accordion>
</Accordions>

## Text Transformers

These can be appended to **any** variable (system or custom) using Unix pipe syntax (`| transformer`) to transform the string output (e.g. `[clip | upper]`).

<Accordions>
<Accordion title="Casing Transformers">
  - `upper`: `HELLO WORLD`
  - `lower`: `hello world`
  - `title`: `Hello World`
  - `sentence`: `Hello world`
</Accordion>

<Accordion title="Programming Transformers">
  - `snake`: `hello_world`
  - `kebab`: `hello-world`
  - `pascal`: `HelloWorld`
  - `camel`: `helloWorld`
</Accordion>

<Accordion title="Web & Utilities">
  - `urlencode`: Percent-encodes characters for use in URLs.
</Accordion>

<Accordion title="Data Extraction">
  Extract values from structured payloads or web content. Pairs perfectly with `[http.get(...)]` and `[file.read(...)]`.
  - `json(path)`: Extracts a value via dot-notation (e.g., `user.hobbies.1`).
  - `html(selector)`: Scrapes HTML inner text using a standard CSS selector (e.g., `.price > span`).
  - `xml(selector)`: Scrapes XML text using CSS selectors.
  - `yaml(path)`: Extracts a value from YAML via dot-notation.
  - `toml(path)`: Extracts a value from TOML via dot-notation.
  - `regexmatch("pattern", [group])`: Extracts a specific regex capturing group (defaults to group 0, the full match).
</Accordion>
</Accordions>
