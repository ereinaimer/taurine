System variables in Taurine use a unified `namespace(args)` call syntax (with bare `[namespace]` as `()` sugar). This reference covers the binder rules, complete catalog, and diagnostic hints.

## Argument Binder Rules

Taurine parses variable call parameters with a single shared binder:

1. **Hybrid Arguments**: Positionals are bound first in parameter order, followed by `name=value` keyword arguments. Positional parameters after named parameters are rejected.
2. **Single-Argument Shape Auto-Detection**: Where documented, a single positional argument automatically infers its parameter name based on value shape (e.g. `[chrono(+1d)]` infers `offset`, `[random(6)]` infers `max`).
3. **Save-Time Diagnostics**: Any system tag containing a dot (`.`), unknown key, missing required parameter, duplicate argument, or obsolete alias is rejected at save time with a helpful hint showing canonical `namespace(...)` syntax.

## Reserved System Roots

| Root | Parameters (Defaults) | Single-Arg Detection | Description |
| :--- | :--- | :--- | :--- |
| `chrono` | `(type=datetime, offset=none, format=per-kind, tz=local)` | `^[+-]` $\rightarrow$ offset; `utc\|local` $\rightarrow$ tz; `date\|time\|datetime` $\rightarrow$ type; else $\rightarrow$ format | Dates, times, calculations, formats, timezones. |
| `clip` | `(index=0)` $\in$ \{0, 1, 2\} | None | Local clipboard history ring. |
| `env` | `(name, [default])` | None | System environment variables. |
| `file` | `(op, ...)` required | None | Read local file contents (`read`, `line`, `lines`). |
| `image` | `(path)` | None | Local PNG/JPEG image injection. |
| `ip` | `(type=public)` $\in$ \{public, local\} | None | Public WAN IP or local LAN IP address. |
| `uuid` | `(version=v4)` $\in$ \{v4, v7\} | None | UUID v4 (random) or v7 (time-ordered). |
| `execute` | `(lang, subject, *args, file=false, silent=false)` | None | Shell script execution (bash, powershell, python, node, cmd). |
| `random` | `(type=int, ...)` | bare number $\rightarrow$ `(int, max)` | Random numbers, strings, passwords, or choice picks. |
| `lorem` | `(type=paragraphs, count)` | bare number $\rightarrow$ count | Placeholder text (paragraphs, sentences, words). |
| `http` | `(op, url)` op $\in$ \{get, status\} | None | HTTP GET body or status code lookup. |
| `mouse` | `(action, ...)` $\in$ \{click, hold, release, move, scroll, pos\} | None | Hardware mouse clicks (`mN`), drag, scroll, position. |
| `key` | `(combo)` | None | Keyboard key press simulation. |
| `delay` | `(duration)` | None | Execution delay in milliseconds/seconds. |
| `cursor` | zero-arg | None | Target caret position after expansion. |
| `newline` | zero-arg | None | Literal line break. |

## Rejection Diagnostics & Obsolete Forms

Taurine rejects old dot-chained or deprecated forms at save time, providing explicit mapping hints:

```text
[date.utc]              -> Error: use canonical chrono(date, tz=utc)
[date.calc(+1d)]        -> Error: use canonical chrono(date)
[time.now]              -> Error: use canonical chrono(time)
[clipboard]             -> Deprecated: use canonical clip (or clip(index))
[uuid(7)]               -> Error: version must be v4 or v7 (e.g. uuid(v7))
[net.publicip]          -> Error: use canonical ip or ip(public)
[net.localip]           -> Error: use canonical ip(local)
[mouse.click]           -> Error: use canonical mouse(click, m1)
[mouse.rclick]          -> Error: use canonical mouse(click, m2)
[mouse.dblclick]        -> Error: use canonical mouse(click, m1, 2)
[mouse.down]            -> Error: use canonical mouse(hold, m1)
[mouse.up]              -> Error: use canonical mouse(release, m1)
[env(HOME=default)]     -> Error: use canonical env(HOME, default)
```

## Text Transformers

Append Unix pipe syntax (`| transformer`) to any system or custom variable tag to modify string output (e.g., `[clip | case(upper)]`).

<Accordions>
<Accordion title="Casing Transformers">
  - `case(upper)`: `HELLO WORLD`
  - `case(lower)`: `hello world`
  - `case(title)`: `Hello World`
  - `case(sentence)`: `Hello world`
</Accordion>

<Accordion title="Programming Transformers">
  - `case(snake)`: `hello_world`
  - `case(kebab)`: `hello-world`
  - `case(pascal)`: `HelloWorld`
  - `case(camel)`: `helloWorld`
</Accordion>

<Accordion title="Web & Utilities">
  - `encode(url)`: Percent-encodes characters for use in URLs.
  - `decode(url)`: Decodes percent-encoded URL components.
  - `clean(url)`: Strips tracking/query parameters and hash/fragment anchors from a URL.
  - `encode(base64)`: Encodes text as Base64.
  - `decode(base64)`: Decodes Base64 text.
</Accordion>

<Accordion title="Color Conversion">
  Auto-detects and converts color formats compliant with W3C CSS Color Level 4:
  - `color(hex)`: Formats as uppercase Hex (e.g. `#FF0000` or `#FF00007F`).
  - `color(rgb)`: Formats as `rgb(R, G, B)` or `rgba(R, G, B, A)`.
  - `color(rgba)`: Formats as `rgba(R, G, B, A)`.
  - `color(hsl)`: Formats as `hsl(H, S%, L%)` or `hsla(H, S%, L%, A)`.
  - `color(hsla)`: Formats as `hsla(H, S%, L%, A)`.
</Accordion>

<Accordion title="Text & Line Utilities">
  - `filter(digits)`: Filters string to keep only digits `0-9`.
  - `filter(alphanumeric)`: Filters string to keep only alphanumeric characters.
  - `count(words)`: Returns the number of whitespace-separated words (e.g. `[clip | count(words)]`).
  - `lines(count)`: Returns the total number of lines (e.g. `[clip | lines(count)]`).
  - `lines(sort[, desc, insensitive, numeric])`: Sorts lines (e.g. `[clip | lines(sort, desc, numeric)]`).
  - `lines(unique)`: Removes duplicate lines globally while maintaining original order.
</Accordion>

<Accordion title="Data Extraction">
  Extract values from structured payloads or web content. Pairs with `[http(get, ...)]`, `[file(read, ...)]`, and `[clip]`.
  - `extract(target)`: Extracts structured patterns natively (`url`, `email`, `phone`, `mention`, `hashtag`, `ip`, `mac`, `path`, `filename`, `directory`, `jwt`, `semver`, `mdcode`, `mdtable`, `mdlist`).
  - `json(path)`: Extracts a value via dot-notation (e.g., `user.hobbies.1`).
  - `json(pretty)`: Indents and formats a JSON payload.
  - `json(minify)`: Strips all formatting whitespace from JSON.
  - `html(selector)`: Scrapes HTML inner text using a standard CSS selector (e.g., `.price > span`).
  - `xml(selector)`: Scrapes XML text using CSS selectors.
  - `yaml(path)`: Extracts a value from YAML via dot-notation.
  - `toml(path)`: Extracts a value from TOML via dot-notation.
  - `regex("pattern", [group])`: Extracts a specific regex capturing group (defaults to group 0).
</Accordion>
