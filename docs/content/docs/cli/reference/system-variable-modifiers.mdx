System variables in Nite use a unified space-separated syntax without unnecessary parentheses (with Unix pipe `|` transformers).

## Reserved System Roots

| Root | Arguments (Defaults) | Description |
| :--- | :--- | :--- |
| `date` | `[offset] [format] [tz]` (order-independent) | Calendar date (`today`, `tomorrow`, `+1d`, `utc`). Default: `YYYY-MM-DD`. |
| `time` | `[offset] [format] [tz]` (order-independent) | Clock time (`+1h`, `-30m`, `utc`). Default: `HH:mm`. |
| `clip` | `[index]` (default `0`) | Local clipboard history ring (`0`, `1`, `2`). |
| `env` | `name [default]` | System environment variables. |
| `file` | `op ...` (`read`, `line`, `lines`) | Read local file contents. |
| `image` | `path` | Local PNG/JPEG image injection. |
| `ip` | zero-arg | Local network interface IP addresses. |
| `uuid` | `[version]` (default `v4`) | UUID v4 (random) or v7 (time-ordered). |
| `run` | `"command" [silent]` | Platform native shell execution. |
| `calc` | `expression` | Inline arithmetic expression evaluation. |
| `random` | `[type] ...` | Random integers, passwords, or choice selections. |
| `lorem` | `[type] [count]` | Placeholder text (paragraphs, sentences, words). |
| `mouse` | `action ...` (`click`, `move`, `scroll`, `pos`) | Hardware mouse operations. |
| `wait` | `duration` (`200ms`, `1.5s`, `500`) | Execution pause delay. |
| `cursor` | zero-arg | Final caret position after expansion. |
| `newline` | `[count]` (default `1`) | Literal newline insertion. |

## Direct Keyboard Directives

Hardware keys can be invoked directly as bare tags without wrapping:

```text
[enter]
[tab]
[esc]
[backspace]
[ctrl+a]
[ctrl+shift+end]
[tab 5]          // repeats key press 5 times
```

---

## Direct Pipeline Filters

Append Unix pipe syntax (`| filter`) to transform text output. Direct filters do not require arguments or nested calls:

```text
[clip | upper]
[clip | lower]
[clip | title]
[clip | snake]
[clip | kebab]
[clip | pascal]
[clip | camel]
[clip | slug]
[clip | trim]
```
