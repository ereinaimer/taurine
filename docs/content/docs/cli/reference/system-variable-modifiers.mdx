- `clipboard`
- `time`
- `date`
- `uuid`
- `env`
- `key`
- `delay`

## Key Modifiers

- `enter`
- `tab`
- `space`
- `esc`
- `up`
- `down`
- `left`
- `right`
- `home`
- `end`
- `pgup`
- `pageup`
- `pgdown`
- `pagedown`
- `insert`
- `ins`
- `backspace`
- `delete`
- `ctrl`
- `shift`
- `alt`
- `super`
- `mod`
- `f1` through `f12`
- `printscreen`
- `prtsc`
- `pause`
- `break`
- `capslock`
- `numlock`
- `scrolllock`

You can combine key tokens with `+`, and any single character token is also allowed.

Examples:

```text
[key.tab]
[key.ctrl+a]
[key.shift+tab]
```

## Delay Modifier

```text
[delay.<u64>ms]
```

Example:

```text
[delay.200ms]
```
