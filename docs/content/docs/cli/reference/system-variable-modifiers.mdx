System variables in Taurine use the format `[root.modifier]`. This reference covers all available reserved roots and their associated modifiers.

## Variable Roots

The following roots are reserved by the Taurine engine and cannot be used as custom variable names.

| Root | Description |
| :--- | :--- |
| `datetime` | Current system datetime in ISO 8601 or custom formats. |
| `time` | Current system time in various formats. |
| `date` | Current system date in various formats. |
| `clip` / `clipboard` | Content of the system clipboard. |
| `cursor` | Directs the final cursor position (placeholder). |
| `uuid` | Unique identifier generation (defaults to v4). |
| `lorem` | Dummy text generation (words, sentences, paragraphs). |
| `random` | Random number, string, choice, and password generation. |
| `net` | Network status and public/local IP lookup. |
| `env` | System environment variables. |
| `file` | Read local file contents. |
| `key` | Keyboard triggers (simulating key presses). |
| `delay` | Timing delays in execution sequences. |
| `mouse` | Mouse clicks, movement, drag-and-drop, and coordinates. |

## Time, Date & Datetime

Method-based API for inserting, calculating, and formatting timestamps, dates, and combined date-times. Universal calculation units (`y`, `m`, `w`, `d`, `h`, `min`, `s`) and LDML formatting tokens are supported across all three roots.

<Accordions>
<Accordion title="datetime">
  - `[datetime]`: Bare root default formatted as ISO 8601 (`YYYY-MM-DDTHH:mm:ss`).
  - `utc`: Switches the context to UTC.
  - `calc(±...<units>)`: Performs temporal calculations using `y` (years), `m` (months), `w` (weeks), `d` (days), `h` (hours), `min`/`i` (minutes), or `s` (seconds). Compound strings like `+1d12h` are supported.
  - `format(<pattern>)`: Formats the output using standard LDML tokens.
</Accordion>

<Accordion title="time">
  - `[time]`: Bare root default formatted as `HH:mm`.
  - `utc`: Switches the time context to UTC.
  - `calc(±...<units>)`: Performs temporal calculations using universal units (`y`, `m`, `w`, `d`, `h`, `min`, `s`).
  - `format(<pattern>)`: Formats the output using standard LDML tokens (date and time tokens are fully supported).
</Accordion>

<Accordion title="date">
  - `[date]`: Bare root default formatted as `YYYY-MM-DD`.
  - `utc`: Switches the date context to UTC.
  - `calc(±...<units>)`: Performs temporal calculations using universal units (`y`, `m`, `w`, `d`, `h`, `min`, `s`).
  - `format(<pattern>)`: Formats the output using standard LDML tokens (date and time tokens are fully supported).
</Accordion>
</Accordions>

## Environment & Clipboard

Interact with your local system state and shell environment.

<Accordions>
<Accordion title="clip / clipboard">
  - `[clip]` / `[clipboard]`: The most recent clipboard item (same as index 0).
  - `[clip(0)]` / `[clipboard(0)]`: Most recent clipboard entry.
  - `[clip(1)]` / `[clipboard(1)]`, `[clip(2)]` / `[clipboard(2)]`: Historical clipboard entries (up to 3 items).
</Accordion>

<Accordion title="env">
  Access any environment variable reachable by the Taurine service.
  - `[env(USER)]` / `[env(USERNAME)]`
  - `[env(PATH)]`
  - `[env(HOME)]` / `[env(USERPROFILE)]`
</Accordion>

<Accordion title="file">
  Read and inject local file contents natively.
  - `[file.read(path)]`: Reads the entire contents of a file (up to 5MB).
  - `[file.line(path, n)]`: Extracts a single 1-indexed line `n`.
  - `[file.lines(path, start, [end])]`: Extracts a line range from `start` to `end` (or to end-of-file if `end` is omitted).
</Accordion>

<Accordion title="net">
  Network status and IP address discovery.
  - `[net.ip]` / `[net.publicip]`: Public WAN IP address (resolved via Cloudflare / ipify).
  - `[net.localip]` / `[net.lip]`: Local network LAN IP address.
  - `[net.online]`: Returns `true` or `false` based on network connectivity.
</Accordion>
</Accordions>

## Triggers & Identity

Modifiers for generating IDs, filler text, or simulating hardware interaction.

<Accordions>
<Accordion title="uuid">
  - `[uuid]`: Generates a UUID v4 by default.
  - `[uuid.v4]`: Explicit version 4 UUID.
  - `[uuid.v7]`: Time-sorted version 7 UUID.
</Accordion>

<Accordion title="random">
  - `[random]`: Generates a random integer between 0 and 100 inclusive.
  - `[random.int]`: Random integer between 0 and 100.
  - `[random.int(max)]`: Random integer between 1 and `max`.
  - `[random.int(min, max)]`: Random integer between `min` and `max`.
  - `[random.choice(a, b, ...)]`: Randomly picks one item from comma-separated choices.
  - `[random.str]` / `[random.str(len)]`: Alphanumeric string (defaults to 16 characters).
  - `[random.pass]` / `[random.pass(len)]`: Secure password string with symbols (defaults to 20 characters).
</Accordion>

<Accordion title="lorem">
  - `[lorem]` / `[lorem(n)]`: Generates lorem ipsum placeholder paragraphs (default 1 paragraph).
  - `[lorem.word]`: Generates default 15 words.
  - `[lorem.word(n)]`: Generates `n` words.
  - `[lorem.sentence]`: Generates default 1 sentence.
  - `[lorem.sentence(n)]`: Generates `n` sentences.
  - `[lorem.paragraph]`: Generates default 1 paragraph.
  - `[lorem.paragraph(n)]`: Generates `n` paragraphs separated by double newlines.
</Accordion>

<Accordion title="key">
  Simulate non-printing keys or keyboard combinations.
  - `[key(enter)]`, `[key(tab)]`, `[key(esc)]`, `[key(space)]`
  - `[key(up)]`, `[key(down)]`, `[key(left)]`, `[key(right)]`
  - `[key(ctrl+v)]`, `[key(alt+tab)]`, `[key(shift+p)]`
  - **See [Keyboard Triggers](/docs/cli/system-variables/keyboard-triggers) for a full list of aliases.**
</Accordion>

<Accordion title="delay">
  Pause execution for a specific duration (milliseconds).
  - `[delay(100ms)]` or `[delay(100)]`
</Accordion>

<Accordion title="mouse">
  Simulate mouse clicks, double clicks, movement, and drag actions.
  - `[mouse.click([button])]`: Click mouse button (defaults to `left`).
  - `[mouse.dblclick([button])]`: Double-click mouse button (defaults to `left`).
  - `[mouse.rclick]`, `[mouse.mclick]`, `[mouse.m4]`, `[mouse.m5]`: Direct button click shorthands.
  - `[mouse.down([button])]` / `[mouse.hold([button])]`: Press and hold button.
  - `[mouse.up([button])]` / `[mouse.release([button])]`: Release held button.
  - `[mouse.move(x, y)]`: Warps pointer to screen coordinates.
  - `[mouse.scroll(delta)]`: Vertical scroll wheel.
  - `[mouse.pos]`: Resolves current pointer coordinates (`x,y`).
  - **Supported Buttons:** `left`, `right`, `middle`, `m4` / `back`, `m5` / `forward`, `m<N>`.
</Accordion>
</Accordions>

## Text Transformers

These can be appended to **any** variable (system or custom) using Unix pipe syntax (`| transformer`) to transform the string output (e.g. `[clip | upper]`).

<Accordions>
<Accordion title="Casing Transformers">
  - `upper`: `HELLO WORLD`
  - `lower`: `hello world`
  - `title`: `Hello World`
  - `sentence`: `Hello world`
</Accordion>

<Accordion title="Programming Transformers">
  - `snake`: `hello_world`
  - `kebab`: `hello-world`
  - `pascal`: `HelloWorld`
  - `camel`: `helloWorld`
</Accordion>

<Accordion title="Web & Utilities">
  - `url.encode`: Percent-encodes characters for use in URLs.
  - `url.decode`: Decodes percent-encoded URL components.
  - `url.clean`: Strips tracking and query parameters from a URL.
</Accordion>

<Accordion title="Color Conversion">
  Auto-detects and converts color formats compliant with W3C CSS Color Level 4:
  - `color.hex`: Formats as uppercase Hex (e.g. `#FF0000` or `#FF00007F`).
  - `color.rgb`: Formats as `rgb(R, G, B)` or `rgba(R, G, B, A)`.
  - `color.rgba`: Formats as `rgba(R, G, B, A)`.
  - `color.hsl`: Formats as `hsl(H, S%, L%)` or `hsla(H, S%, L%, A)`.
  - `color.hsla`: Formats as `hsla(H, S%, L%, A)`.
</Accordion>

<Accordion title="Text & Line Utilities">
  - `digits`: Filters string to keep only digits `0-9`.
  - `alnum`: Filters string to keep only alphanumeric characters.
  - `wordcount`: Returns the number of whitespace-separated words (e.g. `[clip | wordcount]`).
  - `linecount`: Returns the total number of lines (e.g. `[clip | linecount]`).
  - `sortline([options])`: Sorts lines alphabetically or numerically (e.g. `[clip | sortline("numeric", "desc")]`).
  - `uniqline`: Removes duplicate lines globally while maintaining original order.
</Accordion>

<Accordion title="Data Extraction">
  Extract values from structured payloads or web content. Pairs perfectly with `[http.get(...)]` and `[file.read(...)]`.
  - `json(path)`: Extracts a value via dot-notation (e.g., `user.hobbies.1`).
  - `json.pretty`: Indents and formats a JSON payload.
  - `json.minify`: Strips all formatting whitespace from JSON.
  - `html(selector)`: Scrapes HTML inner text using a standard CSS selector (e.g., `.price > span`).
  - `xml(selector)`: Scrapes XML text using CSS selectors.
  - `yaml(path)`: Extracts a value from YAML via dot-notation.
  - `toml(path)`: Extracts a value from TOML via dot-notation.
  - `regex("pattern", [group])`: Extracts a specific regex capturing group (defaults to group 0, the full match).
</Accordion>
</Accordions>
