Nite provides a set of configuration keys to customize its behavior. You can manage these settings using the [`nite config`](/docs/cli/reference/cli-reference#configuration) command or through the interactive TUI settings screen.

## Core & System

Manage system startup, service toggling, and core engine behavior.

<Accordions>
<Accordion title="pause_hotkey">
  The global keyboard shortcut used to toggle the Nite service on and off.
  
  - **Key**: `pause_hotkey`
  - **Alias**: `hotkey`
  - **Default**: `Alt + \``
  - **Example**: `nite config set hotkey "Ctrl + Alt + P"`
</Accordion>

<Accordion title="start_on_boot">
  Determines if Nite should automatically start when your operating system boots.
  
  - **Key**: `start_on_boot`
  - **Alias**: `boot`
  - **Default**: `true`
  - **Values**: `true`, `false`
  - **Example**: `nite config set boot false`
</Accordion>

<Accordion title="auto_update">
  Automatically checks for and installs updates when the Nite service starts.
  
  - **Key**: `auto_update`
  - **Default**: `true`
  - **Values**: `true`, `false`
  - **Example**: `nite config set auto_update false`
</Accordion>

<Accordion title="system_tray_enabled">
  Show or hide the system tray icon in the operating system taskbar when the Nite daemon is running.
  
  - **Key**: `system_tray_enabled`
  - **Alias**: `system_tray`, `tray`
  - **Default**: `true`
  - **Values**: `true`, `false`
  - **Example**: `nite config set tray false`
</Accordion>

<Accordion title="instant_expand">
  Expand snippets instantly upon typing matching keywords, without needing to press Space or Enter.
  
  - **Key**: `instant_expand`
  - **Alias**: `instant`
  - **Default**: `false`
  - **Values**: `true`, `false`
  - **Example**: `nite config set instant true`
</Accordion>

<Accordion title="ignore_fullscreen">
  Disables Nite's text expansion engine, hotkeys, and voice dictation while a fullscreen application (such as a game or presentation) is focused.
  
  - **Key**: `ignore_fullscreen`
  - **Default**: `true`
  - **Values**: `true`, `false`
  - **Example**: `nite config set ignore_fullscreen false`
</Accordion>
</Accordions>

## Formatting

Configure date, time, and combined timestamp templates for inline expansion.

<Accordions>
<Accordion title="inline_date_format">
  Output format template when only a date is resolved during natural language date expansion.
  
  - **Key**: `inline_date_format`
  - **Aliases**: `date_format`, `inline_datetime_date_format`, `inline_date_time_date_format`
  - **Default**: `MMMM D, YYYY`
  - **Example**: `nite config set date_format "YYYY-MM-DD"`
</Accordion>

<Accordion title="inline_time_format">
  Output format template when only a time is resolved during natural language expansion or timezone queries.
  
  - **Key**: `inline_time_format`
  - **Aliases**: `time_format`, `inline_datetime_time_format`, `inline_date_time_time_format`
  - **Default**: `h:mm A`
  - **Example**: `nite config set time_format "HH:mm"`
</Accordion>

<Accordion title="inline_datetime_format">
  Output format template when both a date and time are resolved during natural language expansion.
  
  - **Key**: `inline_datetime_format`
  - **Aliases**: `datetime_format`, `date_time_format`, `inline_datetime_datetime_format`, `inline_date_time_datetime_format`
  - **Default**: `MMMM D, YYYY 'at' h:mm A`
  - **Example**: `nite config set datetime_format "YYYY-MM-DD HH:mm"`
</Accordion>
</Accordions>

## Audio & Feedback

Control audio sound packs and cue volume for system feedback.

<Accordions>
<Accordion title="audio_theme">
  Sound pack theme used for pause, resume, and voice dictation audio feedback cues.
  
  - **Key**: `audio_theme`
  - **Aliases**: `sound_theme`, `audio_pack`, `sound_pack`
  - **Default**: `minimal`
  - **Values**: `minimal`, `arcade`, `mechanical`, `organic`, `scifi`, `rubber`, `zen`
  - **Example**: `nite config set audio_theme mechanical`
</Accordion>

<Accordion title="audio_volume">
  Playback volume percentage for audio cues (clamped between 0 and 100).
  
  - **Key**: `audio_volume`
  - **Aliases**: `sound_volume`, `volume`
  - **Default**: `50`
  - **Values**: `0` – `100`
  - **Example**: `nite config set volume 75`
</Accordion>
</Accordions>

## AI Copilot

Configure AI service provider integrations and custom endpoints.

<Accordions>
<Accordion title="ai_provider">
  The primary AI service provider used for inline AI queries and copilot completions.
  
  - **Key**: `ai_provider`
  - **Default**: `unset`
  - **Values**: `openai`, `claude`, `gemini`, `deepseek`, `groq`, `mistral`, `ollama`, `custom`, etc. (See [AI Copilot](/docs/cli/inline-ai-copilot) for full list)
  - **Example**: `nite config set ai_provider openai`
</Accordion>

<Accordion title="ai_model">
  The specific LLM model used for AI requests. If unset, Nite uses the provider's default model.
  
  - **Key**: `ai_model`
  - **Default**: `unset`
  - **Example**: `nite config set ai_model gpt-4o`
</Accordion>

<Accordion title="ai_custom_endpoint">
  Custom base URL endpoint for OpenAI-compatible or local AI providers (e.g. Ollama or LocalAI).
  
  - **Key**: `ai_custom_endpoint`
  - **Aliases**: `endpoint`, `custom_endpoint`
  - **Default**: `unset`
  - **Example**: `nite config set endpoint http://localhost:11434/v1`
</Accordion>
</Accordions>

## Voice Dictation

Configure hotkeys, vocabulary, device capture, and media playback behavior for voice dictation.

<Accordions>
<Accordion title="voice_ptt_hotkey">
  Global push-to-talk hotkey for speech dictation. Hold down to record speech; release to transcribe and type into the focused app.
  
  - **Key**: `voice_ptt_hotkey`
  - **Aliases**: `voice_ptt`, `ptt_hotkey`, `ptt`
  - **Default**: `win+lctrl`
  - **Example**: `nite config set ptt "Ctrl + Shift + D"`
</Accordion>

<Accordion title="voice_handsfree_hotkey">
  Global toggle hotkey for hands-free continuous dictation. Press once to start recording; press again or hit Escape to finish transcription and insert text.
  
  - **Key**: `voice_handsfree_hotkey`
  - **Aliases**: `voice_handsfree`, `handsfree_hotkey`, `handsfree`
  - **Default**: `win+lctrl+lalt`
  - **Example**: `nite config set handsfree "Ctrl + Shift + H"`
</Accordion>

<Accordion title="voice_dictionary">
  Comma-separated custom vocabulary words or specialized terms used for phonetic boosting and fuzzy correction during speech transcription.
  
  - **Key**: `voice_dictionary`
  - **Aliases**: `voice_vocab`, `voice_words`
  - **Default**: `""` (empty)
  - **Example**: `nite config set voice_dictionary "Kubernetes, Nite, Rust, GraphQL"`
</Accordion>

<Accordion title="voice_input_device">
  Specific audio recording input device name to use for speech capture. If unset, Nite uses the system default recording device.
  
  - **Key**: `voice_input_device`
  - **Aliases**: `voice_device`, `voice_mic`, `input_device`, `mic`, `microphone`
  - **Default**: `unset`
  - **Example**: `nite config set mic "Yeti Nano"`
</Accordion>

<Accordion title="pause_media_while_dictating">
  Automatically pauses active music and media playback while dictating speech, and resumes playback when dictation completes.
  
  - **Key**: `pause_media_while_dictating`
  - **Alias**: `pause_media`
  - **Default**: `true`
  - **Values**: `true`, `false`
  - **Example**: `nite config set pause_media false`
</Accordion>
</Accordions>
