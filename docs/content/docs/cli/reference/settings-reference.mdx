Taurine provides a set of configuration keys to customize its behavior. You can manage these settings using the [`taurine config`](/docs/cli/reference/cli-reference#configuration) command.

## Core Settings

Manage the basic behavior and interaction of the Taurine engine.

<Accordions>
<Accordion title="pause_hotkey">
  The global keyboard shortcut used to toggle the Taurine service on and off.
  
  - **Key**: `pause_hotkey`
  - **Alias**: `hotkey`
  - **Default**: `Alt + \``
  - **Example**: `taurine config set hotkey "Ctrl + Alt + P"`
</Accordion>

<Accordion title="start_on_boot">
  Determines if Taurine should automatically start when your operating system boots.
  
  - **Key**: `start_on_boot`
  - **Alias**: `boot`
  - **Default**: `true`
  - **Values**: `true`, `false`
</Accordion>

<Accordion title="instant_expand">
  Expand snippets instantly when typed, without needing a Space or Enter key.
  
  - **Key**: `instant_expand`
  - **Alias**: `instant`
  - **Default**: `false`
  - **Values**: `true`, `false`
</Accordion>

<Accordion title="action_key">
  Specifies the key used to activate a trigger.
  
  - **Key**: `action_key`
  - **Default**: `enter`
  - **Values**: `enter`, `space`
</Accordion>

<Accordion title="script_timeout">
  Specifies the maximum time (in seconds) a script can run before being terminated.
  
  - **Key**: `script_timeout`
  - **Default**: `15`
</Accordion>
</Accordions>

## User Interface

Customize how Taurine interacts with your system's UI and notifications.

<Accordions>
<Accordion title="spinner_style">
  The visual style of the loading indicator shown during AI generating or long script executions.
  
  - **Key**: `spinner_style`
  - **Alias**: `spinner`
  - **Default**: `braille`
  - **Values**: `braille`, `arc`, `classic`
</Accordion>

<Accordion title="pause_notifications_enabled">
  Whether to show a system notification when Taurine is paused or resumed.
  
  - **Key**: `pause_notifications_enabled`
  - **Alias**: `notifications`
  - **Default**: `false`
  - **Values**: `true`, `false`
</Accordion>

<Accordion title="ignore_fullscreen">
  When set to true, disables Taurine's text expansion engine while a fullscreen application (like a game or presentation) is focused.
  
  - **Key**: `ignore_fullscreen`
  - **Default**: `true`
  - **Values**: `true`, `false`
</Accordion>

<Accordion title="system_tray_enabled">
  Show or hide the system tray icon in the operating system taskbar when the Taurine daemon is running.
  
  - **Key**: `system_tray_enabled`
  - **Alias**: `system_tray`, `tray`
  - **Default**: `true`
  - **Values**: `true`, `false`
</Accordion>
</Accordions>

## AI Copilot

Configure your AI provider integrations and capture behavior.

<Accordions>
<Accordion title="ai_provider">
  The primary AI service used for the Inline AI Copilot.
  
  - **Key**: `ai_provider`
  - **Default**: `unset`
  - **Values**: `openai`, `claude`, `gemini`, `deepseek`, etc. (See [AI Copilot](/docs/cli/inline-ai-copilot) for full list)
</Accordion>

<Accordion title="ai_model">
  The specific LLM used for requests. If unset, Taurine uses the provider's default model.
  
  - **Key**: `ai_model`
  - **Default**: `unset`
  - **Example**: `taurine config set ai_model gpt-4o`
</Accordion>

<Accordion title="ai_custom_endpoint">
  The base URL for the `custom` (OpenAI-compatible) provider.
  
  - **Key**: `ai_custom_endpoint`
  - **Aliases**: `endpoint`, `custom_endpoint`
  - **Default**: `unset`
  - **Example**: `taurine config set endpoint http://localhost:11434/v1`
</Accordion>
<Accordion title="inline_ai_trigger_mode">
  The behavior style of inline AI triggers. When Symmetric, the single trigger symbol is used for both sides.
  
  - **Key**: `inline_ai_trigger_mode`
  - **Alias**: `delimiter_mode`
  - **Default**: `Symmetric`
  - **Values**: `Symmetric`, `Asymmetric`
  - **Example**: `taurine config set inline_ai_trigger_mode Asymmetric`
</Accordion>

<Accordion title="inline_ai_trigger">
  The single trigger symbol used to both open and close an inline AI prompt. (Only used if `inline_ai_trigger_mode` is Symmetric)
  
  - **Key**: `inline_ai_trigger`
  - **Alias**: `symmetric_delimiter`
  - **Default**: `^`
  - **Example**: `taurine config set inline_ai_trigger "~"`
</Accordion>

<Accordion title="inline_ai_trigger_open">
  The trigger text used to start an inline AI prompt. (Only used if `inline_ai_trigger_mode` is Asymmetric)
  
  - **Key**: `inline_ai_trigger_open`
  - **Alias**: `open_delimiter`
  - **Default**: `>>`
  - **Example**: `taurine config set inline_ai_trigger_open "[["`
</Accordion>

<Accordion title="inline_ai_trigger_close">
  The trigger text used to end an inline AI prompt. (Only used if `inline_ai_trigger_mode` is Asymmetric)
  
  - **Key**: `inline_ai_trigger_close`
  - **Alias**: `close_delimiter`
  - **Default**: `<<`
  - **Example**: `taurine config set inline_ai_trigger_close "]]"`
</Accordion>
</Accordions>

## Inline Trigger Assist

Control the behavior of the headless assist features and inline conversion features for word triggers.

<Accordions>
<Accordion title="inline_tab_completion_enabled">
  Enables or disables the ability to cycle through matching word triggers using the `Tab` and `Shift + Tab` keys.
  
  - **Key**: `inline_tab_completion_enabled`
  - **Alias**: `inline_tab_completion`
  - **Default**: `true`
  - **Values**: `true`, `false`
</Accordion>

<Accordion title="inline_emoji_enabled">
  Enables or disables the ability to expand Unicode emojis by typing shortcodes (e.g. `:rocket`).
  
  - **Key**: `inline_emoji_enabled`
  - **Alias**: `inline_emoji`
  - **Default**: `true`
  - **Values**: `true`, `false`
</Accordion>

<Accordion title="inline_datetime_enabled">
  Enables or disables the ability to expand natural language date and time descriptions on Enter.
  
  - **Key**: `inline_datetime_enabled`
  - **Alias**: `inline_datetime`
  - **Default**: `true`
  - **Values**: `true`, `false`
</Accordion>

<Accordion title="inline_currency_to_words_enabled">
  Enables or disables the ability to automatically convert currency-prefixed numbers inline into their spelled-out English word equivalents on Enter.
  
  - **Key**: `inline_currency_to_words_enabled`
  - **Alias**: `inline_currency_to_words`, `inline_currency_words`
  - **Default**: `false`
  - **Values**: `true`, `false`
</Accordion>
</Accordions>

## Service RPC

Configure communication and security settings for the gRPC connection between the clients (TUI / CLI) and the background service process.

<Accordions>
<Accordion title="rpc_mode">
  The transport protocol used for service RPC. Local owner-only sockets (Unix domain sockets on macOS/Linux, and Named Pipes on Windows) are recommended for local owner-only security. TCP loopback mode can be used if cross-machine RPC is required.
  
  - **Key**: `rpc_mode`
  - **Alias**: `mode`
  - **Default**: `socket` (all platforms)
  - **Values**: `socket`, `tcp`
</Accordion>

<Accordion title="rpc_host">
  The IP address / network interface the background service binds to in TCP mode.
  
  - **Key**: `rpc_host`
  - **Alias**: `host`
  - **Default**: `127.0.0.1`
</Accordion>

<Accordion title="rpc_port">
  The TCP port the gRPC RPC server listens on when running in TCP mode.
  
  - **Key**: `rpc_port`
  - **Alias**: `port`
  - **Default**: `50051`
</Accordion>

<Accordion title="rpc_token">
  The secret Bearer authorization token used to secure connection channels across all transport modes (TCP, sockets, and named pipes) for defense-in-depth security. This token is automatically generated as a secure UUID v4 on startup if not set, and is stored in the owner-restricted local database.
  
  - **Key**: `rpc_token`
  - **Alias**: `token`
  - **Default**: *Auto-generated*
</Accordion>
</Accordions>
