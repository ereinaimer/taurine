## Content Variables

- `[clipboard]`: current clipboard text
- `[time.*]`: current time values
- `[date.*]`: current date values
- `[uuid]` and `[uuid.*]`: generated UUIDs
- `[env.VAR_NAME]`: environment variable value

Examples:

```text
[clipboard]
[time.now]
[date.iso]
[uuid.v7]
[env.USERPROFILE]
```

## Directive Variables

- `[cursor]`: move the final caret position
- `[key.*]`: press a key or key combination
- `[delay.*]`: pause between steps

Examples:

```text
[cursor]
[key.tab]
[key.ctrl+shift+end]
[delay.200ms]
```

## Chaining And Nesting

You can chain valid modifiers and transformers:

```text
[time.now.upper]
[date.month_name.lower]
```

## Important Cursor Rule

If a snippet contains any `[key.*]` or `[delay.*]` directive, `[cursor]` is treated as literal text instead of moving the caret.

## Escaping

Use backslashes to keep special tags as plain text:

```text
\[cursor\]
\[key.tab\]
```
