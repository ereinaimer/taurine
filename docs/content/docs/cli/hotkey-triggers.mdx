Nite entries fire from four invocation kinds: **Word**, **Hotkey**, **Regex**, and **Voice** — one entry can mix them (see [Managing Triggers](/docs/cli/trigger-management)).

While Word Triggers are activated by typing a word directly (e.g., `gs `) and pressing Enter, **Hotkey Triggers** are global keyboard shortcuts that execute a trigger immediately when pressed, regardless of your current text state.

<Callout title="Global Shortcuts" type="info">
  Hotkey triggers are global while the Nite service is running. They do not require typed text and do not use the "Backspace Undo" mechanism because no trigger text was typed.
</Callout>

## Side-Specific Modifiers

Nite supports **side-specific modifier** triggers, allowing you to bind different triggers to the left and right physical keys (e.g., Left Shift vs. Right Shift).

### Generic vs. Specific Matching

*   **Generic Modifiers** (`ctrl`, `shift`, `alt`, `meta`): Match the requirement if **either** the left or right physical key is pressed.
*   **Side-Specific Modifiers** (`lctrl`, `ralt`, etc.): Match **only** if that specific physical key is pressed.

### Conflict & Overlap Rules

Nite prevents ambiguous triggers by checking for overlaps:
*   **Overlap**: `alt+m` conflicts with `lalt+m` because the generic `alt` requirement overlaps with the specific `lalt`.
*   **Independence**: `lalt+m` and `ralt+m` are considered separate identities and can coexist.
*   **Invalid Combinations**: You cannot combine a generic and side-specific version of the same family (e.g., `ctrl+lctrl+k` is rejected).

## Creating Hotkey Triggers

To create a hotkey trigger, pass the combo to the `--hotkey` flag with the `add` command (repeatable — one combo per occurrence).

### Standard Text Expansion
Map a keyboard shortcut to a text snippet.

```bash
nite add "git status[key(enter)]" --hotkey "ctrl+shift+g"
```

### Combined with Word Triggers
Attach a hotkey to an existing word entry so either one fires it:

```bash
nite add gs "git status[key(enter)]" --hotkey "ctrl+shift+g"
```

### Script Triggers
Trigger a shell script with a hotkey.

```bash
nite add script winget-install -l powershell "winget install [pkg=git]" --hotkey "ctrl+shift+w" --hotkey "ctrl+alt+w"
```

### Side-Specific Examples
Bind different productivity tools to the same base key using different sides:

```bash
# Bind Right Alt + M to open a typing test
nite add script "Start-Process https://monkeytype.com" --hotkey "ralt+m" -l powershell -m silent

# Bind Left Alt + M to open Gmail
nite add script "Start-Process https://mail.google.com" --hotkey "lalt+m" -l powershell -m silent
```

## Hotkey Syntax & Canonicalization

Nite automatically normalizes (canonicalizes) your hotkey strings before storing them. This ensures that different ways of writing the same shortcut are treated as identical.

These are all equivalent and will be stored as `ctrl+shift+g`:
- `Ctrl + ShIFT + G`
- `Shift+Ctrl+G`
- `control + shift + g`

### Modifier Order
Nite enforces a canonical order for modifiers:
1. `ctrl`
2. `shift`
3. `alt`
4. `meta`

Example: `meta+alt+ctrl+shift+g` becomes `ctrl+shift+alt+meta+g`.

## Supported Keys & Aliases

### Modifiers

Nite recognizes generic modifiers and their side-specific variants.

| Family | Generic | Left Side Aliases | Right Side Aliases |
| :--- | :--- | :--- | :--- |
| **Ctrl** | `ctrl`, `control` | `lctrl`, `leftctrl`, `leftcontrol` | `rctrl`, `rightctrl`, `rightcontrol` |
| **Shift** | `shift` | `lshift`, `leftshift` | `rshift`, `rightshift` |
| **Alt** | `alt`, `opt`, `option` | `lalt`, `leftalt`, `leftoption` | `ralt`, `rightalt`, `rightoption`, `altgr` |
| **Meta** | `meta`, `cmd`, `win`, `super`, `mod` | `lmeta`, `lwin`, `leftsuper`, `leftcmd` | `rmeta`, `rwin`, `rightsuper`, `rightcmd` |

<Callout title="Platform Implementation" type="info">
  On Linux, Nite uses `evdev` to track physical hardware scan codes directly. On Windows and macOS, it uses system-level hooks (`rdev`) to distinguish between virtual key codes for left/right variants.
</Callout>

### Special Keys
| Key | Aliases |
| :--- | :--- |
| **Enter** | `enter`, `return` |
| **Escape** | `esc`, `escape` |
| **Delete** | `delete`, `del` |
| **Arrows** | `up`, `down`, `left`, `right`, `arrowup`, etc. |
| **Backtick** | `` ` ``, `backtick`, `grave`, `~`, `tilde` |

### Numpad vs. Top-Row
Nite distinguishes between the top-row number keys and the numeric keypad.
- `ctrl+1`: Top-row digit 1.
- `ctrl+num1`: Numpad digit 1.

## Validation & Safety

To prevent accidental system lockouts or conflicts, Nite validates every hotkey against several safety rules.

### Rejected Hotkeys

Nite will reject the following shortcuts:
- **Modifier-only**: e.g., `ctrl+shift` (must include a base key).
- **Multi-base chords**: e.g., `ctrl+k+p` (only one non-modifier key allowed).
- **Unknown keys**: Any key not recognized by the parser.
- **Dangerous OS Shortcuts**: 
  - `ctrl+c`, `ctrl+v`, `ctrl+x`, `ctrl+z`, `ctrl+a`, `ctrl+s` (Windows/Linux)
  - `cmd+c`, `cmd+v`, `cmd+x`, etc. (macOS)
  - `alt+tab`, `alt+f4` (Windows/Linux)
  - `cmd+tab`, `cmd+q` (macOS)
- **Nite Reserved**: `alt+` ` is reserved for Nite's global pause hotkey.

<Callout title="Side-Specific Safety" type="warning">
  Safety rules and reservations apply to **both generic and side-specific variants**. For example, both `ctrl+c` and `lctrl+c` are rejected to prevent interfering with your system's copy command. Similarly, `lalt+` ` and `ralt+` ` are also reserved.
</Callout>

## Important Limitations

### Typed Arguments
Unlike word triggers, hotkeys accept no typed arguments at all.
- Word triggers fill fields inline (`gs;argument ` fills `[name=default]`).
- Pressing `ctrl+shift+g` has no way to supply values at runtime, so every variable uses its default value.

### Target OS
Hotkey triggers are **desktop-only**. They are not supported for `android` or `ios` target operating systems. You can, however, bind the same hotkey to different actions on different desktop platforms:

```bash
nite add "Windows Project" --hotkey "ctrl+shift+p" --os windows
nite add "Linux Project" --hotkey "ctrl+shift+p" --os linux
```
