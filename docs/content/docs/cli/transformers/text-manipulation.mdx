---
title: Text Manipulation
description: Perform powerful string operations like truncation, replacement, and reversal.
---

These transformers allow you to modify the content of a string beyond simple casing changes. All operations are **UTF-8 char-aware**, meaning they correctly handle multi-byte characters like emojis.

### Available Modifiers

| Modifier | Description | Example |
| :--- | :--- | :--- |
| `trim` | Removes leading and trailing whitespace | `"  hi  "` → `"hi"` |
| `length` | Returns the number of characters | `"aßc"` → `3` |
| `wordcount` | Returns the number of whitespace-separated words | `"Hello world"` → `2` |
| `truncate(n)` | Limits text to `n` characters | `"abcdef"` → `"abc..."` |
| `replace(old, new)` | Replaces all occurrences of `old` with `new` | `"a,b,c"` → `"a;b;c"` |
| `remove(str)` | Strips all occurrences of `str` | `"banana"` → `"ba"` |
| `substring(s, e)` | Precise char-aware slicing | `"naïve"` → `"ïve"` |
| `stripall` | Removes ALL whitespace | `" a b c "` → `"abc"` |
| `onlydigit` | Keeps only `0-9` | `"A-10-9"` → `"109"` |
| `onlyalphanumeric` | Keeps only letters and numbers | `"a-b_1!"` → `"ab1"` |

### Advanced Manipulation

#### Regex Replacement
The `regexreplace(pattern, replacement)` transformer uses the Rust [regex](https://docs.rs/regex/) crate. It supports Perl-like syntax and captures groups. If the pattern is invalid, the transformer fails gracefully and returns the original text.

<Transformation
  template='[0 | regexreplace("([a-z]),([A-Z])", "$1 $2")]'
  input=">text:'a,B c,D'"
  result="a B c D"
/>

#### Precise Slicing
Unlike byte-based slicing in many languages, `substring(start, end)` is fully UTF-8 char-aware. Indices are 0-based.

<Transformation
  template="[0 | substring(1, 3)]"
  input=">text:'aßc'"
  result="ßc"
/>

#### Word Count
Returns the total number of words in a string, ignoring leading, trailing, or multiple adjacent spaces.

<Transformation
  template="[0 | wordcount]"
  input=">text:'  This is a   sentence.  '"
  result="4"
/>
