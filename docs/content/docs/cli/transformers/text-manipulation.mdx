---
title: Text Manipulation
description: Perform powerful string operations like truncation, replacement, slicing, and filtering.
---

These transformers allow you to modify text content using clean Unix pipe syntax with space-separated arguments. All operations are **UTF-8 char-aware**, correctly handling multi-byte characters and emojis.

### Available Modifiers

| Filter | Description | Example |
| :--- | :--- | :--- |
| `trim` | Removes leading and trailing whitespace | `"  hi  "` → `"hi"` |
| `truncate n` | Limits text to `n` characters | `truncate 20` |
| `repeat count` | Repeats text `count` times (uncapped) | `repeat 500` |
| `replace old new` | Replaces occurrences of `old` with `new` | `replace "foo" "bar"` |
| `replace regex p r` | Replaces regex matches of `p` with `r` | `replace regex "(\d+)" "[$1]"` |
| `slice start end` | Precise char-aware slicing | `slice 1 3` |
| `strip whitespace` | Removes all whitespace | `strip whitespace` |
| `strip emoji` | Removes all emoji characters from text | `strip emoji` |
| `count chars` | Returns total character count | `count chars` |
| `count words` | Returns total word count | `count words` |
| `filter digits` | Keeps only digits `0-9` | `filter digits` |
| `filter alphanumeric` | Keeps only letters and numbers | `filter alphanumeric` |

### Direct Trimming (`| trim`)

Trims surrounding whitespace directly without nested function calls:

```text
[clip | trim]
```

### Uncapped String Repetition (`| repeat count`)

Repeats strings any desired number of times (e.g. generating long divider rules), protected by a safe 200 KB buffer cap:

```text
['=' | repeat 80]
```

### Space-Separated Arguments

Transformers accept space-separated arguments after pipes:

```text
[clip | truncate 40]
[clip | replace "TODO" "DONE"]
```
