---
title: Casing
description: Transform text between different naming conventions and capitalization styles.
---

Casing transformers ensure user-provided arguments fit the exact style requirements of your code, commit messages, URLs, or documentation.

All casing transformations follow the uniform `case(style)` call syntax.

### Reference Table

| Modifier | Description | Example |
| :--- | :--- | :--- |
| `case(upper)` | ALL UPPERCASE | `hello` → `HELLO` |
| `case(lower)` | all lowercase | `HELLO` → `hello` |
| `case(sentence)` | Capitalize first char | `hello world` → `Hello world` |
| `case(title)` | Title Case | `hello world` → `Hello World` |
| `case(snake)` | snake_case | `HelloWorld` → `hello_world` |
| `case(kebab)` | kebab-case | `HelloWorld` → `hello-world` |
| `case(pascal)` | PascalCase | `hello_world` → `HelloWorld` |
| `case(camel)` | camelCase | `hello_world` → `helloWorld` |
| `case(slug)` | URL slug | `Hello World 2026! 🌴` → `hello-world-2026` |

### Sentence Case

Unlike `case(title)`, `case(sentence)` only capitalizes the very first character of the string, leaving the rest of the text as-is.

<Transformation
  template="[0 | case(sentence)]"
  input="text:'hello from taurine'"
  result="Hello from taurine"
/>

### Consistency in Code

Use `case(camel)` for variables and `case(pascal)` for classes or types when generating code snippets.

<Transformation
  template="class [0 | case(pascal)] { const [0 | case(camel)] = true; }"
  input="name:'user_service'"
  result="class UserService { const userService = true; }"
/>
