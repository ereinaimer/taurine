---
title: Casing
description: Transform text between different naming conventions and capitalization styles.
---

Casing transformers are the most common way to ensure that user-provided arguments fit the requirements of your code, commit messages, or documentation.

Taurine uses strict, short identifiers for all casing modifiers for clean Unix pipe syntax without redundant aliases.

### Reference Table

| Modifier | Description | Example |
| :--- | :--- | :--- |
| `upper` | ALL UPPERCASE | `hello` → `HELLO` |
| `lower` | all lowercase | `HELLO` → `hello` |
| `sentence` | Capitalize first char | `hello world` → `Hello world` |
| `title` | Title Case | `hello world` → `Hello World` |
| `snake` | snake_case | `HelloWorld` → `hello_world` |
| `kebab` | kebab-case | `HelloWorld` → `hello-world` |
| `pascal` | PascalCase | `hello_world` → `HelloWorld` |
| `camel` | camelCase | `hello_world` → `helloWorld` |
| `shoutysnake` | SHOUTY_SNAKE_CASE | `hello world` → `HELLO_WORLD` |
| `shoutykebab` | SHOUTY-KEBAB-CASE | `hello world` → `HELLO-WORLD` |
| `train` | Train-Case | `hello_world` → `Hello-World` |
| `mocking` | mOcKiNg CaSe | `hello` → `hElLo` |
| `leet` | l33t 5p34k | `elite` → `31173` |

### Sentence Case

Unlike `title`, `sentence` only capitalizes the very first character of the string, leaving the rest of the text as-is.

<Transformation
  template="[0 | sentence]"
  input=">text:'hello from taurine'"
  result="Hello from taurine"
/>

### Consistency in Code

Use `camel` for variables and `pascal` for classes or types when generating code snippets.

<Transformation
  template="class [0 | pascal] { const [0 | camel] = true; }"
  input=">name:'user_service'"
  result="class UserService { const userService = true; }"
/>
