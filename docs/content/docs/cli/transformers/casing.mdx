---
title: Casing
description: Transform text between different naming conventions and capitalization styles.
---

Casing transformers ensure user-provided arguments and variable outputs fit the exact style requirements of your code, commit messages, URLs, or documentation.

In Taurine's unified syntax, common casing transformers can be chained directly as pipeline filters:

```text
[clip | upper]
[clip | lower]
[clip | title]
[clip | snake]
[clip | kebab]
[clip | pascal]
[clip | camel]
[clip | slug]
```

### Reference Table

| Direct Filter | Legacy Form | Description | Example |
| :--- | :--- | :--- | :--- |
| `upper` | `case(upper)` | ALL UPPERCASE | `hello` → `HELLO` |
| `lower` | `case(lower)` | all lowercase | `HELLO` → `hello` |
| `title` | `case(title)` | Title Case | `hello world` → `Hello World` |
| `snake` | `case(snake)` | snake_case | `HelloWorld` → `hello_world` |
| `kebab` | `case(kebab)` | kebab-case | `HelloWorld` → `hello-world` |
| `pascal` | `case(pascal)` | PascalCase | `hello_world` → `HelloWorld` |
| `camel` | `case(camel)` | camelCase | `hello_world` → `helloWorld` |
| `slug` | `case(slug)` | URL slug | `Hello World 2026! 🌴` → `hello-world-2026` |
| — | `case(sentence)` | Capitalize first char | `hello world` → `Hello world` |

### Consistency in Code

Use `| camel` for variables and `| pascal` for classes or types when generating code snippets:

<Transformation
  template='class [$name = "sample" | pascal] { const [$name = "sample" | camel] = true; }'
  input="name;'user_service'"
  result="class UserService { const userService = true; }"
/>
