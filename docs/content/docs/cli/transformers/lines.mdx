---
title: Line Manipulation
description: Extract and process multi-line text content using the unified lines(action) transformer family.
---

Line transformers allow you to process multi-line data from the clipboard, variables, or command outputs. They automatically handle both `\n` (Unix) and `\r\n` (Windows) line endings.

All line operations are grouped under the `lines(...)` transformer namespace.

### Available Modifiers

| Modifier | Description |
| :--- | :--- |
| `lines(first)` | Extracts only the first line |
| `lines(last)` | Extracts only the last line |
| `lines(count)` | Counts the total number of lines |
| `lines(compact)` | Strips blank lines |
| `lines(prefix, str)` | Prepends `str` to every line |
| `lines(suffix, str)` | Appends `str` to every line |
| `lines(join, delim)` | Collapses lines into one, using `delim` |
| `lines(split, delim)` | Expands one line into many, breaking at `delim` |
| `lines(unique)` | Deduplicates lines globally while preserving first-occurrence order |
| `lines(sort)` | Sorts lines alphabetically (optional args: `"desc"`, `"insensitive"`, `"numeric"`) |

### Prefix and Suffix

These are useful for quickly formatting lists, such as adding bullet points or semicolon line-endings.

<Transformation
  template='[clip | lines(prefix, "> ")]'
  input="clip:'Line 1\nLine 2'"
  result="> Line 1\n> Line 2"
/>

### Unique & Deduplication

Remove duplicate lines globally while maintaining original order:

<Transformation
  template='[clip | lines(unique)]'
  input="clip:'orange\napple\norange\nbanana'"
  result="orange\napple\nbanana"
/>

### Line Count

Count total number of lines:

<Transformation
  template='[clip | lines(count)]'
  input="clip:'Line 1\nLine 2\nLine 3'"
  result="3"
/>

### Sorting

Sort lines alphabetically or numerically (`desc`, `insensitive`, `numeric`):

<Transformation
  template='[clip | lines(sort, "numeric")]'
  input="clip:'10\n2\n1.5'"
  result="1.5\n2\n10"
/>
