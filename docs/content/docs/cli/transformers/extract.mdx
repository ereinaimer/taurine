---
title: Pattern Extractors
description: Pull structured data (URLs, emails, numbers, paths, markdown) from raw text.
---

The `extract(...)` suite of transformers provides powerful regular expressions and parsers to extract structured data from unstructured text, web pages, or clipboard contents.

Unlike standard text replacements, these extractors find all matches within the input and return them as a newline-separated list.

### Available Extractors

| Transformer | Description |
| :--- | :--- |
| `extract(url)` | Pulls valid `http/https` URLs. |
| `extract(email)` | Pulls valid email addresses. |
| `extract(phone)` | Pulls phone numbers (various formats). |
| `extract(mention)` | Pulls `@` handles (e.g., `@username`). |
| `extract(hashtag)` | Pulls `#` tags (e.g., `#rust`). |
| `extract(ip)` | Pulls IPv4 and IPv6 addresses. |
| `extract(mac)` | Pulls hardware MAC addresses. |
| `extract(path)` | Pulls POSIX and Windows file/directory paths. |
| `extract(filename)` | Pulls standalone filenames or extracts filenames from paths. |
| `extract(directory)` | Pulls directories or extracts the parent directory of paths. |
| `extract(jwt)` | Pulls JSON Web Tokens (JWT). |
| `extract(semver)` | Pulls Semantic Versions (e.g., `v1.2.3`). |
| `extract(mdcode)` | Pulls the inner contents of triple-backtick markdown blocks. |
| `extract(mdtable)` | Pulls markdown-formatted tables. |
| `extract(mdlist)` | Pulls bulleted or numbered lists. |

### Examples

#### Extracting URLs
Easily scrape a webpage or clipboard text for all links:
<Transformation
  template="[clipboard | extract(url)]"
  input="clipboard:'Check https://taurine.in and https://github.com'"
  result="https://taurine.in\nhttps://github.com"
/>

#### Extracting Directories
If you have a log file or a system prompt, you can extract the directory paths directly:
<Transformation
  template="[clipboard | extract(directory)]"
  input="clipboard:'The config is at /etc/nginx/nginx.conf'"
  result="/etc/nginx"
/>

#### Extracting Code Blocks
When piping outputs from AI or Markdown documents, you can extract the raw code:
<Transformation
  template="[clipboard | extract(mdcode)]"
  input="clipboard:'Here is the code:\n```rust\nfn main() {}\n```'"
  result="fn main() {}"
/>
