Formatting transformers help you manage quotes and other wrapping characters around your variables.

### Quote Management

These modifiers are essential for ensuring that user input is correctly escaped or quoted when inserted into code snippets or JSON payloads.

| Modifier | Description | Example |
| :--- | :--- | :--- |
| `quote` | Wraps in `"` | `hi` → `"hi"` |
| `squote` | Wraps in `'` | `hi` → `'hi'` |
| `backtick` | Wraps in ``` ` ``` | `hi` → `` `hi` `` |
| `unquote` | Removes leading/trailing quotes | `"hi"` → `hi` |

### Practical Examples

#### Quoting for JSON
Ensure a variable is safely wrapped in double quotes for a JSON structure.

<Transformation
  template='{ "value": [0 | quote] }'
  input=">text:'hello world'"
  result='{ "value": "hello world" }'
/>

#### Inline Code Formatting
Wrap dynamic strings in backticks for markdown or documentation snippets.

<Transformation
  template="Use the [0 | backtick] variable."
  input=">text:'user_id'"
  result="Use the `user_id` variable."
/>

#### Safely Unquoting
If you are passing a variable that might already be quoted (like a clipboard item), use `unquote` to normalize it before processing.

<Transformation
  template="[clipboard | unquote | upper]"
  input='>clip:"taurine"'
  result="TAURINE"
/>
