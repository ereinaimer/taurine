Formatting transformers manage quotes and wrapping characters around your variables using explicit function calls.

### Quote Management

These transformers ensure user input is correctly escaped or quoted when inserted into code snippets, markdown, or JSON payloads.

| Modifier | Description | Example |
| :--- | :--- | :--- |
| `wrap(doublequote)` | Wraps text in double quotes `"` | `hi` → `"hi"` |
| `wrap(singlequote)` | Wraps text in single quotes `'` | `hi` → `'hi'` |
| `wrap(backtick)` | Wraps text in backticks ``` ` ``` | `hi` → `` `hi` `` |
| `unwrap(quotes)` | Removes surrounding quotes | `"hi"` → `hi` |

### Examples

#### Quoting for JSON
Ensure a variable is safely wrapped in double quotes for a JSON structure.

<Transformation
  template='{ "value": [0 | wrap(doublequote)] }'
  input="text:'hello world'"
  result='{ "value": "hello world" }'
/>

#### Inline Code Formatting
Wrap dynamic strings in backticks for markdown or documentation snippets.

<Transformation
  template="Use the [0 | wrap(backtick)] variable."
  input="text:'user_id'"
  result="Use the `user_id` variable."
/>

#### Safely Unquoting
If you are passing a variable that might already be quoted, use `unwrap(quotes)` to normalize it before processing.

<Transformation
  template="[clipboard | unwrap(quotes) | case(upper)]"
  input='clipboard:"taurine"'
  result="TAURINE"
/>
