## Introduction

Taurine is a fast and secure text expander and keyboard automation tool

## How it Works

To use Taurine, you type in the trigger character followed by the trigger word you set and finally a space. Here, try it for yourself!

Tweak the trigger word and the expansion to whatever you like.

## CLI Basics

Ready to use the real tool? Here are the four commands you'll use most:

<Steps>
### Start the Engine
```bash
taurine up
```
This boots the background service.

### Add your first expansion
```bash
taurine add gm "Good morning!"
```
Now type `>gm` followed by `Space` in any app. You can also use `Tab` or `Up/Down` to cycle through matching triggers and history after typing the trigger character.

### List your triggers
```bash
taurine list
```
See everything you've configured so far.

### Remove an automation
```bash
taurine rm gm
```
Clean up triggers you no longer need.
</Steps>
