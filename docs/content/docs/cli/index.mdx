## Installation

Prebuilt binaries can be installed instantly using our quick-install scripts:

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/ereinaimer/taurine/main/install.ps1 | iex
```

### macOS / Linux (Bash)
```bash
curl --proto '=https' --tlsv1.2 -LsSf https://raw.githubusercontent.com/ereinaimer/taurine/main/install.sh | sh
```

## CLI Basics

Ready to use the real tool? Here are the four commands you'll use most:

<Steps>
### Start the Engine
```bash
taurine up
```
This boots the background service.

### Add your first expansion
```bash
taurine add gm "Good morning!"
```
Now type `gm` followed by `Space` in any app. You can also use `Tab` to cycle through matching triggers.

### List your triggers
```bash
taurine list
```
See everything you've configured so far.

### Remove a trigger
```bash
taurine rm gm
```
Clean up triggers you no longer need.
</Steps>
