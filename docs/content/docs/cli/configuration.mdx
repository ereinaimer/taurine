---
title: Configuration
description: View and change Taurine settings from the command line.
---

## List Current Settings

```bash
taurine config list
taurine config ls
```

## Set A Value

```bash
taurine config set trigger_char /
taurine config set start_on_boot true
taurine config set ai_delimiter_mode Asymmetric
```

## Reset A Value

```bash
taurine config reset trigger_char
```

Reset everything:

```bash
taurine config reset --all
```

## Common Settings

| Setting | Default | Description |
| :--- | :--- | :--- |
| `trigger_char` | `>` | The character typed before an automation trigger word. |
| `pause_hotkey` | ``Alt + ` `` | Global hotkey to pause/resume the Taurine engine. |
| `pause_notifications_enabled` | `true` | Whether to show system notifications when pausing. |
| `start_on_boot` | `true` | Enables/disables automatic startup on login. |
| `spinner_style` | `braille` | Style of the thinking spinner (`braille`, `arc`, `classic`). |
| `ai_provider` | - | The default AI provider for Inline AI commands. |
| `ai_model` | - | The default model for the selected AI provider. |
| `ai_custom_endpoint` | - | Custom OpenAI-compatible URL for the `custom` provider. |
| `ai_delimiter_mode` | `Symmetric` | The behavior mode (`Symmetric` or `Asymmetric`) for inline AI delimiters. |
| `ai_delimiter_open` | `>>` | The opening text boundary for inline AI prompts. |
| `ai_delimiter_close` | `<<` | The closing text boundary for inline AI prompts. |
| `inline_tab_completion_enabled` | `true` | Enables or disables inline `Tab` / `Shift+Tab` completion. |
| `inline_history_enabled` | `true` | Enables or disables inline `Up Arrow` / `Down Arrow` trigger history. |

## Helpful Aliases

You can use these shorter aliases when running `taurine config set`:

| Alias | Real Setting |
| :--- | :--- |
| `trigger` | `trigger_char` |
| `hotkey` | `pause_hotkey` |
| `notifications` | `pause_notifications_enabled` |
| `boot` | `start_on_boot` |
| `spinner` | `spinner_style` |
| `delimiter_mode` | `ai_delimiter_mode` |
| `delimiter_open` | `ai_delimiter_open` |
| `delimiter_close` | `ai_delimiter_close` |
| `endpoint` | `ai_custom_endpoint` |
| `custom_endpoint` | `ai_custom_endpoint` |
| `inline_tab_completion` | `inline_tab_completion_enabled` |
| `inline_history` | `inline_history_enabled` |

<Callout title="Startup setting" type="info">
  Changing `start_on_boot` also tries to update the OS startup hook right away, so the setting and
  the actual startup behavior stay in sync.
</Callout>
