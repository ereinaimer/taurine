## Trigger Types

Taurine supports two ways to activate a trigger:

1. **Word Triggers**: Typed words expanded directly with Enter (e.g., `brb`).
2. **Hotkey Triggers**: Global keyboard shortcuts (e.g., `ctrl+shift+g`).

## Adding Triggers

### Word Triggers (Default)

To create a new text expansion triggered by a typed word, use the `add` or `set` command:

```bash
taurine add brb "Be right back"
```

If you add a trigger that already exists, Taurine will automatically update it with the new content.

### Hotkey Triggers

To create a trigger configured as a keyboard shortcut, use the `--hotkey` flag:

```bash
taurine add --hotkey "ctrl+shift+g" "git status[key.enter]"
```

For more details on hotkey syntax and validation, see the [Hotkey Triggers](/docs/cli/hotkey-triggers) page.

### Multi-OS Support
You can restrict triggers to specific operating systems, or make them universal:

```bash
taurine add sig "Sent from Taurine" --os all      # Works everywhere
taurine add sig "Sent from Windows" --os windows  # Windows only
```

### Tagging Snippets
You can organize your triggers using tags. Add tags using the `--tag` flag when adding a word trigger, hotkey trigger, or script:

```bash
taurine add gm "Good morning!" --tag work,email
taurine add brb "Be right back" --tag casual --tag priority
```

You can specify the `--tag` option multiple times or pass a comma-separated list of tags.

## How to Trigger

### Word Triggers
Taurine is natively triggerless — there is no prefix character. Type the **word** and press **Enter** to expand it.

```text
brb[Enter]
```

<Callout title="Expansion Key" type="info">
  Expansion is activated by the **Enter** key. To expand instantly without pressing Enter, enable `instant_expand`.
</Callout>

### Hotkey Triggers
Hotkey triggers execute immediately when the keyboard shortcut is pressed. They do not require typed text or a trailing space.

## Inline Trigger Assist

Taurine provides a headless **inline trigger assist** to help you quickly find and select your word triggers as you type. This feature works directly inside your active text field—no popups, overlays, or command palettes are required. It includes **Tab completion** for matching triggers.

### Usage

1. Type a few characters of a **word trigger**.
2. Use the following keys to navigate:

| Key | Action |
| :--- | :--- |
| **Tab** | Cycle forward through matching word triggers. |
| **Shift + Tab** | Cycle backward through matching word triggers. |

### Tab Completion

Completion works on the typed word directly — there is no prefix character. After typing at least one character of a trigger (e.g., `g`), press `Tab` to cycle through all triggers that start with that prefix. Suggestions are sorted alphabetically.

1. Type a word prefix (e.g., `g`).
2. Press **Tab**.
3. If any of your word triggers start with `g` (e.g., `gc` or `gs`), completion activates immediately, rewriting the word in your active buffer to the first sorted suggestion (e.g., `gc`).
4. Pressing **Tab** cycles forward through the matching suggestions. All cycled Tab keystrokes are swallowed to prevent OS focus shifts.
5. Pressing **Shift + Tab** cycles backward through suggestions.
6. Pressing **Enter** will expand the selected suggestion.
7. If no triggers match the prefix when you press **Tab**, the key event passes through to the OS normally (e.g., to insert an indentation tab or move focus).

* **Wraparound**: Cycling is infinite; reaching the end of the list wraps back to the beginning.
* **Word Triggers Only**: Completion only suggests word triggers. Hotkey triggers are never suggested.

### Control Keys

While assist is active, Taurine manages several keys to ensure a smooth experience:

* **Escape / other keys**: While a suggestion is active, cancels assist and passes the key through, keeping the current selection.
* **Backspace**: If a Tab suggestion is selected, deletes the last character of your typed input so you can refine your search.
* **Space**: Types a literal space character into the current query.
* **Modified Tabs**: Shortcuts like `Alt + Tab` or `Ctrl + Tab` will cancel assist and pass through to the system normally.

<Callout title="AI Mode Priority" type="info">
  Inline trigger assist is automatically disabled when you are in **Interactive AI Capture** mode. This ensures that arrow keys and Tab function normally while you are drafting a prompt for the AI.
</Callout>

<Callout title="Word Triggers Only" type="info">
  Trigger assist only suggests **word triggers**. Hotkey triggers are not included because they are triggered by global shortcuts rather than typed text.
</Callout>

### Configuration

Tab completion is enabled by default. If you prefer to disable it (e.g., to prevent conflicts with terminal shells or specific applications), you can do so using the CLI:

```bash
# Disable Tab completion
taurine config set inline_tab_completion false
```

When disabled, the `Tab` key is passed through to the system normally. Disabling assist does not affect your ability to expand word triggers using `Enter` or use the inline AI copilot.

## Viewing Your Triggers

List all configured triggers with `taurine list` (alias: `ls`). You can sort them to find your most used snippets:

```bash
taurine list --sort usage --desc  # See your most used triggers first
taurine ls --sort recent          # Alias 'ls' also works
```

### Filtering by Tag
You can filter listed triggers to only show those that have a specific tag:

```bash
taurine list --tag work
```

## Deleting Triggers

Remove one or more triggers using the `rm` command (aliases: `remove`, `delete`):

```bash
taurine rm brb gm sig
taurine delete obsolete_trigger
```

### Deleting by Tag
You can remove all triggers that have a specific tag by using the `--tag` flag:

```bash
taurine delete --tag obsolete_trigger
```

## Validation & Limits

Taurine enforces several guardrails when creating or updating triggers to prevent data corruption and ensure reliable behavior across all platforms.

### Size Limits

| Field | Maximum |
|-------|---------|
| Trigger string (word, hotkey, regex) | 200 characters |
| Text output | 100 KB |
| Script content | 1 MB |
| Trigger display name | 200 characters |
| Description | 1000 characters |

### Tags

Tags are automatically normalized on save:
- Leading/trailing whitespace is stripped
- All tags are lowercased
- Duplicates are removed
- Maximum 20 tags per trigger
- Maximum 50 characters per tag

### App Filters

Application filters (`--include-apps` / `--exclude-apps`) are automatically cleaned:
- Whitespace around each entry is trimmed
- Empty entries from stray commas are removed
- Only `exe:`, `class:`, and `title:` prefixes are allowed

### Dead Reference Detection

If a trigger's output contains a `[use("name")]` reference to a trigger that doesn't exist, the creation is rejected at save time.

### Duplicate Name Warning

Creating or updating a trigger whose display name matches an existing trigger produces a warning (not an error), visible in daemon logs and CLI output.

### Unicode Normalization

All trigger strings and keyboard input are NFC-normalized, ensuring accented characters (like `é`) typed via dead-key sequences on Windows match their stored form reliably.
