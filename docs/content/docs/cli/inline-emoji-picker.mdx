Taurine features a built-in lightweight **Inline Emoji Picker** that lets you search and insert Unicode emojis directly as you type. Simply type a configurable trigger character (default `:`) followed by a shortcode prefix, select a match, and press **Space** or **Enter**.

<Callout title="Snippet Priority" type="info">
  If your configured emoji trigger is the same as the global snippet trigger, snippets take absolute precedence. If your input matches an active snippet trigger, the snippet expands instead of the emoji.
</Callout>

## Usage

1. **Trigger Autocomplete**: Type the emoji trigger (default `:`) at a word boundary (start of line or after whitespace) followed by letters or numbers.
2. **Cycle Matches**: Press **Tab** (or **Shift + Tab** to go backward) to cycle through matching emoji shortcode labels (e.g., `:rock` cycles through `:rocket`, `:rooster`, etc.).
3. **Expand**: Press Enter (or your configured Action Key) to replace the shortcode label with the actual Unicode emoji (e.g. `:rocket` becomes `🚀`).

## Hyphen-Only Standardization

All emoji shortcode suggestions are standardized to use hyphens (`-`) rather than underscores (`_`). For example, the suggested completion will show `:heart-eyes` rather than `:heart_eyes`.

To make typing easier, you can input underscores (`_`) or hyphens (`-`) interchangeably when typing queries. For example, typing `:heart_ey` or `:heart-ey` will both match and suggest `:heart-eyes`.

<Callout title="Inline Tab Completion & Instant Expand Conflicts" type="warning">
  - **Inline Tab Completion**: Cycling through matched suggestions relies on the global **Inline Tab Completion** setting (`inline_tab_completion_enabled`, default `true`). If this is disabled, pressing Tab will not cycle matches.
  - **Instant Expand**: If **Instant Expand** (`instant_expand`, default `false`) is enabled, typing the full name of an emoji (e.g. `:rocket`) will instantly replace it with the emoji, bypassing autocomplete cycling. To cycle suggestions under Instant Expand, press Tab on a partial match (e.g. `:rock`).
</Callout>

## Emoji Shortcode Reference

Taurine uses standard Unicode shortcode labels (the same shortcode format used by GitHub, Slack, and Discord). To find the exact label for any emoji:
- You can reference standard emoji cheat sheets or lists (such as the GitHub Emoji List).
- Keep in mind that Taurine maps all underscores (`_`) in these standard lists to hyphens (`-`). For example, the standard `heart_eyes` shortcode is written and autocompleted as `heart-eyes` in Taurine.

## Configuration

You can configure or turn off this feature by modifying the settings:

- **Inline Emoji**: A global toggle (`inline_emoji_enabled`) to enable or disable the feature (default `true`).
- **Inline Emoji Trigger Character**: The character used to trigger the emoji autocomplete (`inline_emoji_trigger_char`, default `:`).
