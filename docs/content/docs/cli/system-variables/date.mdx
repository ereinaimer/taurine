The `[date.*]` namespace allows you to insert the current, previous, or next day's date in several standard formats.

## Standard Formats

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[date.iso]` | Standard YYYY-MM-DD | `2026-04-21` |
| `[date.short]` | MM/DD/YYYY | `04/21/2026` |
| `[date.long]` | Month DD, YYYY | `April 21, 2026` |

## Relative Dates

Taurine can automatically calculate yesterday and tomorrow. If no format modifier is provided, **ISO** (`YYYY-MM-DD`) is used by default.

- `[date.tomorrow]` (Defaut: ISO)
- `[date.tomorrow.short]`
- `[date.tomorrow.long]`
- `[date.yesterday]` (Default: ISO)
- `[date.yesterday.iso]`

## Component Variables

Extract specific parts of the current date for use in filenames, metadata, or custom formatting.

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[date.weekday]` | Full name of the day | `Tuesday` |
| `[date.year]` | 4-digit year | `2026` |
| `[date.month]` | 2-digit month (01-12) | `04` |
| `[date.month_name]` | Full month name | `April` |
| `[date.day]` | 2-digit day of month | `21` |
