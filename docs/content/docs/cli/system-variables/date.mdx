title: Date

The `[date.*]` namespace allows you to insert the current, previous, or next day's date in several standard formats.

## Standard Formats

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[date.iso]` | Standard YYYY-MM-DD | `2026-04-21` |
| `[date.short]` | MM/DD/YYYY | `04/21/2026` |
| `[date.long]` | Month DD, YYYY | `April 21, 2026` |

## Relative Dates

Taurine can automatically calculate yesterday and tomorrow, supporting all standard formats through nested modifiers.

- `[date.tomorrow]` / `[date.tomorrow.iso]`
- `[date.yesterday.short]`
- `[date.tomorrow.long]`

## Component Variables

Extract specific parts of the current date for use in filenames or metadata.

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[date.weekday]` | The day of the week | `Tuesday` |
| `[date.year]` | Current year | `2026` |
| `[date.month]` | Numerical month (01-12) | `04` |
| `[date.month_name]` | Full month name | `April` |
| `[date.day]` | Numerical day (01-31) | `21` |
