---
title: Date
description: Using date system variables in Taurine.
---

The `[date]` system variable allows you to insert the current date. It uses a zero-property, method-based API that lets you modify the context (UTC vs Local), perform date calculations, and format the output using standard LDML tokens.

By default, `[date]` outputs the current local date in ISO format (`YYYY-MM-DD`).

## Methods

You can chain methods onto `[date]` to customize the output.

| Method | Description | Example |
| :--- | :--- | :--- |
| `.utc` | Switches the date context to UTC instead of local time. | `[date.utc]` |
| `.calc(±...<units>)` | Adds or subtracts time. Requires a `+` or `-` sign. | `[date.calc(+1d)]` |
| `.format(<pattern>)` | Formats the date using LDML tokens. | `[date.format(YYYY)]` |

### Method Chaining

Methods are evaluated from left to right.
```text
[date.utc.calc(+1w2d).format(dddd)]
```

## Date Formatting

Use the `.format()` method to format the date.

### LDML Tokens

| Token | Description | Example Output |
| :--- | :--- | :--- |
| `YYYY` | 4-digit year | `2026` |
| `YY` | 2-digit year | `26` |
| `MMMM` | Full month name | `April` |
| `MMM` | Short month name | `Apr` |
| `MM` | 2-digit month | `04` |
| `M` | 1 or 2 digit month | `4` |
| `DD` | 2-digit day of month | `08` |
| `D` | 1 or 2 digit day of month | `8` |
| `dddd` | Full weekday name | `Tuesday` |
| `ddd` | Short weekday name | `Tue` |

*Note: Time-related tokens (like `HH`, `mm`, `ss`) cannot be used in `date.format()`.*

### Literal Text Escaping

To include literal text inside your format string without it being interpreted as a token, wrap the text in single quotes (`'...'`). This avoids any collision with Taurine's macro syntax.

```text
[date.format('Today is' dddd, MMMM D, YYYY)]
```
*Output: Today is Tuesday, April 8, 2026*

## Date Calculations

Use the `.calc()` method to calculate relative dates. You **must** provide a leading `+` or `-` sign, followed by amounts and unit characters. You can combine multiple units.

### Supported Date Units

| Unit | Description |
| :--- | :--- |
| `d` | Days |
| `w` | Weeks |
| `m` / `M` | Months |
| `y` / `Y` | Years |

*Note: Time-related units (like `h`, `s`) cannot be used in `date.calc()`.*

### Examples

- `[date.calc(+1d)]` (Tomorrow)
- `[date.calc(-1w)]` (Last week)
- `[date.calc(+1y2M)]` (1 year and 2 months from now)
