Taurine can do more than expand text; it automates your keyboard directly with bare key directives and pauses.

## Bare Key Directives

Directives simulate hardware key presses. In unified syntax, standard key names do not require enclosing parentheses:

```text
[enter]
[tab]
[esc]
[backspace]
[ctrl+a]
[ctrl+shift+end]
```

### Key Repeats

To repeat a key press multiple times, pass a count after the key name:

```text
[tab 5]
[down 3]
[backspace 10]
```

### Supported Keys

- **Navigation**: `tab`, `enter`/`return`, `esc`/`escape`, `up`, `down`, `left`, `right`, `home`, `end`, `pgup`/`pageup`, `pgdown`/`pagedown`, `insert`/`ins`, `delete`/`del`.
- **Numpad**: `num_enter`, `num_add`, `num_sub`, `num_mul`, `num_div`, `num_dec`, `num_0` through `num_9`.
- **Modifiers**: `ctrl`/`control`, `alt`/`option`/`opt`, `shift`, `win`/`mod`/`super`/`meta`/`cmd`/`command`.
- **Special Characters**: `backtick`, `grave`, `tilde`, `minus`, `dash`, `equal`, `equals`, `backslash`, `semicolon`, `quote`, `apostrophe`, `comma`, `dot`, `period`, `slash`, `lbracket`, `rbracket`, `space`.
- **Function Keys**: `f1` through `f12`.
- **Alphanumeric**: Any single letter (`a`-`z`).

## Wait Directives

Use `[wait ...]` to pause snippet execution for a specific duration. This is essential when a snippet performs an action (like tabbing) that requires the target application UI to update.

```text
[enter] [wait 200ms] [tab]
[ctrl+s] [wait 1.5s] [ctrl+w]
[wait 500] // defaults to milliseconds
```
