Taurine can do more than just expand text; it can automate your keyboard. By using `[key(...)]` and `[delay(...)]` directives, you can create powerful sequences that navigate forms, trigger IDE shortcuts, or wait for UI transitions.

## Key Directives

The `[key(...)]` variable simulates a hardware key press. You can use standard key names or complex combinations inside the parentheses.

### Supported Keys

- **Navigation**: `tab`, `enter`/`return`, `esc`/`escape`, `up`, `down`, `left`, `right`, `home`, `end`, `pgup`/`pageup`, `pgdown`/`pagedown`, `insert`/`ins`, `delete`/`del`.
- **Modifiers**: `ctrl`/`control`, `alt`/`option`/`opt`, `shift`, `win`/`mod`/`super`/`meta`/`cmd`/`command`.
- **Special Characters**: `backtick`, `grave`, `tilde`, `minus`, `dash`, `equal`, `equals`, `backslash`, `semicolon`, `quote`, `apostrophe`, `comma`, `dot`, `period`, `slash`, `lbracket`, `rbracket`.
- **Function Keys**: `f1` through `f12`.
- **Alphanumeric**: Any single letter (`a`-`z`) or number (`0`-`9`).

### Key Combinations

Combine keys using the `+` symbol. Modifiers should come first. You can chain multiple modifiers for complex shortcuts.

```text
[key(ctrl+a)]            // Select All
[key(ctrl+shift+end)]    // Select to end of document
[key(mod+space)]         // Open Launcher (Spotlight/Start Menu)
[key(alt+f4)]            // Close Window (Windows/Linux)
```

## Delay Directives

Use `[delay(...)]` to pause the execution of a snippet for a specific duration. This is essential when a snippet performs an action (like tabbing) that requires the UI to catch up. You can pass a millisecond count, include the `ms` suffix, or specify seconds using the `s` suffix (which also supports decimals).

```text
[key(tab)][delay(100ms)][key(tab)]
[key(tab)][delay(1.5s)][key(tab)]
[key(tab)][delay(2s)][key(tab)]
```

## Advanced Example: Form Auto-Fill

Combine text, keys, and delays to fill out a structured form with a single trigger.

<Transformation
  template="[0][key(tab)][delay(50ms)][1][key(tab)][delay(50ms)][2][key(enter)]"
  input=">fill:erein:Aimer:admin "
  result="erein[TAB]aimer[TAB]admin[ENTER]"
/>
