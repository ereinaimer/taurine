The `[exec.*]` namespace lets you embed shell commands directly inside any trigger template. When the snippet expands, Taurine executes the command live and injects its output at that exact position — no separate script trigger required.

<Callout title="Progressive Injection" type="info">
  Taurine does not wait for the script to finish before typing. It immediately injects all preceding text, then shows a live spinner at the `[exec.*]` position, and replaces it with the output when execution completes.
</Callout>

## Syntax

All `exec` variables follow a parenthesized syntax. The command or file path lives inside `(...)`, which prevents any collision with dot-notation transformers or default value assignments.

```text
[exec.<lang>(<command>)]
```

### Supported Languages

| Namespace | Interpreter | Command Executed |
| :--- | :--- | :--- |
| `[exec.bash(...)]` | `bash` | `bash -c "<command>"` |
| `[exec.powershell(...)]` | `powershell` | `powershell -NoProfile -Command "<command>"` |
| `[exec.python(...)]` | `python` | `python -c "<command>"` |
| `[exec.node(...)]` | `node` | `node -e "<command>"` |
| `[exec.cmd(...)]` | `cmd` | `cmd /C "<command>"` |

### Silent Execution Mode

Add `.silent` right after `exec` to run the command in the background. The command executes asynchronously, but **nothing is typed or injected** into your active text field.

```text
[exec.silent.bash(curl -s https://hooks.slack.com/...)]
```

This is ideal for side effects — like logging, Webhook triggers, or native system notifications.

### Inline Scripts vs Script Files

You can pass shell commands inline, or read from a local script file on disk.

```text
# Inline command string
[exec.bash(curl -s https://api.ipify.org)]

# Script file path
[exec.bash.file(/absolute/path/to/script.sh)]
```

### Compiled Script Portability

When you create or update a trigger containing a script file variable, Taurine reads the script from disk, compresses it using ZStandard, and packs it into the database as a compiled asset. The template is updated to point to the asset hash.

At expansion time, Taurine loads the script content directly from the database and executes it. This means your script triggers are completely self-contained and portable—they will continue to function even if you delete, move, or modify the original script file on disk.

<Callout title="File Not Found on Creation" type="warn">
  If the script file path does not exist on disk at the time you add or update the trigger, Taurine will return an error and block creation.
</Callout>

### Passing Arguments to a File

Chain `.args(...)` after the file path to pass positional arguments to the script.

```text
[exec.bash.file(/path/to/template.sh).args(arg1, arg2)]
[exec.python.file(~/scripts/gen.py).args(--format, json, --count, 5)]
```

Arguments are split on commas. Whitespace around each argument is trimmed.

## Transformer Chaining

You can chain any [format modifier](/docs/cli/dynamic-variables/transformers) using pipe syntax after the closing parenthesis, just like with any other system variable.

```text
[exec.bash(whoami) | upper]
[exec.bash(git rev-parse --abbrev-ref HEAD) | kebab]
```

The script executes first, then the transformer is applied to its output.

### Background Side Effect with Text

Triggers a system notification silently and still injects the surrounding text.

```text
Deployment triggered.[exec.silent.powershell(New-BurntToastNotification -Text 'Deployed!')]
```

The snippet injects `Deployment triggered.` and exits. The notification fires independently.

## Technical Details

- **Timeout**: Every `exec` command has a maximum execution time of **20 seconds**. If it exceeds this limit, Taurine terminates the process and injects `[Error: script timed out after 20s]`.
- **Environment**: Commands run with the same environment as the Taurine service. Ensure your interpreter (`python`, `node`, etc.) is available in your system's `PATH`.
- **Abort**: If you click the mouse while the spinner is active, Taurine will kill the running process and stop injection immediately.
- **Transformers come last**: When chaining transformers, they must always appear after the closing `)` of the command using pipe syntax. For example, `[exec.bash(whoami) | upper]` is valid.

<Callout title="Security Warning on Import" type="warn">
  When importing triggers that contain `[exec.*]` variables, Taurine will display a security warning and ask for confirmation. Only import triggers from sources you trust.
</Callout>
