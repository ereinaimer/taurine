The `[net.*]` namespace provides essential utilities for checking internet connectivity, resolving public and local IP addresses, and monitoring local port listeners.

## Reference Table

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[net.ip]` | Public WAN IP address | `198.51.100.42` |
| `[net.lip]` | Local LAN IPv4 address | `192.168.1.15` |
| `[net.online]` | Internet connection status | `true` or `false` |
| `[net.port(n)]` | Local TCP port listener check | `true` or `false` |

## Usage Details

### Public IP (`net.ip`)
`[net.ip]` resolves your external WAN IP address using a lightweight, non-blocking HTTP lookup with a strict timeout.

```text
Public IP: [net.ip] -> "Public IP: 198.51.100.42"
```

### Local IP (`net.lip`)
`[net.lip]` resolves your primary active local IPv4 address. It automatically filters out loopback (`127.0.0.1`) and unassigned interfaces.

```text
Local IP: [net.lip] -> "Local IP: 192.168.1.15"
```

### Online Check (`net.online`)
`[net.online]` performs a fast 500ms connection check to verify active internet connectivity, returning `true` or `false`.

```text
Online: [net.online] -> "Online: true"
```

### Local Port Check (`net.port(n)`)
`[net.port(n)]` checks if a specific local TCP port `n` (e.g. `8080` or `5432`) is currently listening for connections.

```text
Dev Server Running: [net.port(8080)] -> "Dev Server Running: true"
```

## Combined Example

You can combine network variables and transformers for dynamic status templates:

```text
IP: [net.ip] ([net.lip]) | Status: [net.online]
```
