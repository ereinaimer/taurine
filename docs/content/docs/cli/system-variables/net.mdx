---
title: Network & IP Lookups
description: Fetch public and local IP addresses and network status.
---

The `[net.*]` system variable suite allows you to inject network diagnostics into snippets.

## Available Variables

| Variable | Description |
| :--- | :--- |
| `[net.publicip]` | Fetches public IP address asynchronously. |
| `[net.localip]` | Fetches local network IP address. |
| `[net.online]` | Returns `true` or `false` indicating internet connectivity. |
