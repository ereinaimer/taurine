The `env` system variable allows you to access any environment variable currently defined on your system with optional default fallbacks.

## Usage

Use `env` with the variable name, followed by an optional fallback value:

```text
[env USER]
[env HOME]
[env PORT 8080]
```

*Note: Variable names are case-sensitive on most Unix-like platforms.*

## Practical Example

You can use environment variables to build system-specific file paths or identify the active user:

```text
Author: [env USERNAME | title] | Profile: [env USERPROFILE]
```

## Security Note

Environment variables can contain sensitive information (like API tokens or passwords). Be careful when sharing snippets that use `[env ...]` to ensure you are not unintentionally exposing private machine data.
