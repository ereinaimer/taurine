The `[env(...)]` namespace allows you to access any environment variable currently defined on your system. This is a secure and flexible way to customize snippets based on the user's machine configuration without hardcoding paths or identities.

## Usage

Use `env(...)` with the name of the environment variable inside parentheses. Optional single or double quotes are supported around variable names.

```text
User: [env(USER)]
Home: [env("HOME")]
Shell: [env('SHELL')]
```

*Note: Variable names are case-sensitive on most systems.*

## Practical Example

You can use environment variables to build system-specific file paths or identify the active user in a shared team snippet.

<Transformation
  template="Author: [env(USERNAME).title] | Profile: [env(USERPROFILE)]"
  input="whoami "
  result="Author: Erein | Profile: C:\Users\erein"
/>

## Security Note

Environment variables can contain sensitive information (like `API_KEY`). Be careful when sharing snippets that use `[env(...)]` to ensure you aren't unintentionally exposing private data to third parties.
