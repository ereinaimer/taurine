The `[random.*]` namespace allows you to inject randomized data directly into your snippets. This is ideal for generating test data, passwords, unique tokens, or making probabilistic choices within a template.

All `random` variables follow a function-call syntax. Arguments are passed inside `(...)` and are optional for most variants.

## Available Variants

### Numbers & Logic

| Variable | Description | Default | Example |
| :--- | :--- | :--- | :--- |
| `[random.int(min, max)]` | Random integer between min and max. | `0..99` | `42` |

### Strings & Identifiers

| Variable | Description | Default | Example |
| :--- | :--- | :--- | :--- |
| `[random.str(len)]` or `[random.string]` | Alphanumeric string (A-Z, a-z, 0-9). | `16` | `aB3k9Lp2Qx8vM1nQ` |
| `[random.pass(len)]` or `[random.password]` | Secure string with special symbols. | `20` | `kL9!pQ#zR2*j$m8W` |

### Choices

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[random.choice(a, b, ...)]` | Pick one item from a comma-separated list. | `one` |

## Usage Details

### Nested Choices
The `random.choice` variant supports nested structures and commas within options if they are enclosed in parentheses.

```text
[random.choice(env(USER), guest)]
```

### Transformer Chaining
You can chain any [format modifier](/docs/cli/dynamic-variables/transformers) after the variable.

```text
[random.str(8) | upper] -> "KLMNPQRS"
[random.choice(apple, banana) | kebab]
```

---

## Technical Constraints

- **Length Limit**: Any generated string is capped at **4096 characters** to prevent memory exhaustion.
- **Synchronous Resolution**: `random` variables resolve instantly in memory without network latency.
