---
title: HTTP Requests
description: Perform HTTP requests and inject responses into templates.
---

The `http` system variable makes HTTP requests and returns response body or status code.

### Syntax & Parameters

```text
[http(op, url)]
```

- **`op`** (required): Operation type (`get` or `status`).
- **`url`** (required): Target URL (assumes `https://` if protocol omitted).

### Examples

| Expression | Description |
|---|---|
| `[http(get, example.com)]` | Perform HTTP GET and inject body text |
| `[http(status, https://example.com)]` | Return HTTP response status code (e.g. `200`) |
| `[http(op=get, url=api.github.com)]` | Named parameter syntax |
