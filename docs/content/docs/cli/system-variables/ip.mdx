---
title: IP Address
description: Fetch local machine network interface IP addresses synchronously.
---

The `ip` system variable retrieves local IP addresses directly from system network interfaces without making external network calls.

### Syntax

```text
[ip]
```

Returns comma-separated IPv4 and IPv6 addresses of all active local network interfaces. If no active network interfaces are found, it falls back to `127.0.0.1`.

### Examples

| Expression | Example Output | Description |
|---|---|---|
| `[ip]` | `192.168.1.5, 10.0.0.12` | Local network interface addresses |
| `[ip | split(',') | trim]` | Extracts and trims individual interface IPs |
