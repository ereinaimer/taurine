The `[clipboard]` variable is one of the most powerful system variables in Taurine. It allows you to take text you've copied and immediately use it inside a template, with full support for [transformers](/docs/cli/dynamic-variables/transformers).

Taurine maintains a secure, in-memory history of your recent copies, enabling you to reference previous items without re-copying them.

## Usage

Simply insert `[clipboard]` into your snippet to inject the most recent item. You can access previous clipboard entries using a simple index syntax:

| Variable | Description |
| :--- | :--- |
| `[clipboard]` | The most recent clipboard item (same as index 0). |
| `[clipboard(0)]` | The most recent clipboard item. |
| `[clipboard(1)]` | The second most recent item. |
| `[clipboard(2)]` | The third most recent item. |

Taurine keeps a "ring buffer" of the last 3 items. If you request an index that hasn't been filled yet (e.g., you've only copied one thing since starting Taurine), the variable will resolve to an empty string.

```text
The selected text was: "[clipboard]"
```

## Smart Filtering

Taurine is designed to keep your history clean and your system fast. To achieve this, it uses several smart filters:

- **Size Limit**: Only text payloads under **64KB** are recorded. If you copy a massive log file or image, Taurine ignores it to prevent memory bloat.
- **Smart Deduplication**: If you copy the same text twice in a row, Taurine ignores the second event to avoid cluttering your history.
- **Junk Filter**: Items consisting entirely of whitespace, newlines, or tabs are automatically ignored.
- **Text Only**: Only text data is captured. Images, file lists, and other binary data are skipped.

<Callout title="Platform Support" type="info">
  History tracking is currently optimized for Windows. Basic clipboard support is available on Linux and macOS, with full history engine support pending.
</Callout>

## Privacy & Security

We treat your clipboard data with the highest security standards:

- **Zero-Trace**: Your clipboard history is never saved to your hard drive. It lives entirely in volatile memory and is permanently wiped whenever the Taurine daemon restarts.
- **Sensitive Data Detection**: Taurine automatically detects and ignores "Transient Data" flags used by popular password managers like 1Password and Bitwarden. If you copy a secret, Taurine won't store it in the history buffer.

## Transforming Clipboard Data

You can sanitize or reformat copied text on the fly. This is useful for generating branch names, formatting code, or creating links.

### Examples

#### Multi-Copy Branch Generator
Converts a copied task ID and task title into a git-ready branch slug.

<Transformation
  template="git checkout -b feature/[clipboard(1)]-[clipboard(0).kebab]"

/>

#### Clean Link
Encodes a copied URL to ensure it's safe for use in identifiers.

```text
https://example.com/api/search?q=[clipboard.urlencode]
```
