The `[file.*]` namespace allows you to natively read and inject content from files located on your local disk.

## Methods

### `[file.read(path)]`

Reads the entire contents of a file and injects it into your snippet output.

```text
License terms:
[file.read(C:\Users\aimer\LICENSE.txt)]
```

- **File Path**: Must be an absolute path (or start with `~` for the home directory).
- **Size Limit**: Files larger than **5MB** will return `[Error: File size exceeds 5MB limit]`.
- **UTF-8 Support**: Reads standard UTF-8 text files. Binary files will return an error or produce unreadable sequences.

---

### `[file.read_line(path, line)]`

Reads a single, 1-indexed line from a target file.

```text
Today's quote:
[file.read_line(C:\notes\quotes.txt, 1)]
```

If the requested line number exceeds the file's total lines, Taurine inserts an empty string.

---

### `[file.read_line(path, start, end)]`

Extracts a contiguous range of lines from a target file.

```text
Header section:
[file.read_line(C:\notes\changelog.md, 1, 10)]
```

Lines within the specified range (inclusive) are joined with standard line breaks.

---

## Combining with Transformers

You can pipe file content directly into transformers to modify it before expansion.

```text
[file.read(~/.bashrc) | upper]
[file.read_line(~/todo.txt, 1) | trim]
```

---

## Example Usage: Random Line Selection

If you have a file named `quotes.txt` with one quote per line, you can configure a trigger to randomly pull a single quote.

```text
[file.read_line(C:\notes\quotes.txt, 1, 5) | trim]
```
---

## Technical Constraints

<Callout type="warn" title="5MB Size Limit">
To prevent memory exhaustion on the service thread and ensure zero-latency execution, **all file reads are strictly limited to 5MB.** 
</Callout>

Taurine is designed for stability. If a file cannot be found, permissions are denied, or the file size exceeds the 5MB limit, the engine **will not crash**. Instead, it intercepts the error and returns a formatted inline text string.

For example, if the file is missing, the engine will expand to `[Error: The system cannot find the file specified.]` directly in your text field, allowing you to easily identify and fix the issue.

## Examples

### Injecting a Signature
You can store your email signature in a `.txt` file and inject it effortlessly.

<Transformation
  trigger=";sig"
  template="Best regards,\n\n[file.read(~/Documents/signature.txt)]"
  output="Best regards,\n\nJohn Doe\nSenior Engineer | Taurine Inc.\njohn@taurine.app"
/>

### Pulling a Random Quote
If you have a file named `quotes.txt` with one quote per line, you can configure a trigger to randomly pull a single quote.

<Transformation
  trigger=";quote"
  template="Here is your quote for the day:\n[file.read_line(~/Documents/quotes.txt, 1)]"
  output="Here is your quote for the day:\nThe only way to do great work is to love what you do."
/>
