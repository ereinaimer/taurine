---
title: Realistic Mock Data
description: Generate high-quality realistic placeholder data for essential entity fields.
---

The `[mock.*]` namespace provides realistic data generation tools to populate templates with authentic-looking names, addresses, internet profiles, and professional data.

## Available Variants

### Identity
| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[mock.name]` | Full name (First + Last) | `John Doe` |
| `[mock.first_name]` | A single first name | `Jane` |
| `[mock.last_name]` | A single last name | `Smith` |

### Geography
| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[mock.address]` | Full street address | `123 Main St, Springfield, IL 62704` |
| `[mock.city]` | City name | `New York` |
| `[mock.state]` | State or province | `California` |
| `[mock.zip_code]` | Postal code | `90210` |
| `[mock.country]` | Country name | `United States` |

### Web & Internet
| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[mock.email]` | Free-provider email address | `jane.doe@gmail.com` |
| `[mock.username]` | Internet username | `jdoe99` |
| `[mock.domain]` | Domain name | `example.com` |

### Professional & Financial
| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[mock.company]` | Company name | `Acme Corp` |
| `[mock.job_title]` | Professional job title | `Software Engineer` |
| `[mock.credit_card]` | Formatted credit card number | `1234-5678-9012-3456` |
| `[mock.phone_number]` | Formatted phone number | `555-010-9988` |
| `[mock.cell_number]` | Mobile phone number | `1-555-010-9988` |

## Usage Details

### Transformer Chaining
All generated mock data can be piped through [Transformers](/docs/cli/dynamic-variables/transformers) for final formatting.

```text
[mock.name | upper] -> "JOHN DOE"
[mock.city | lower] -> "new york"
[mock.job_title | kebab] -> "software-engineer"
```

## Examples

### Populating a Contact Form
Use a combination of identity and geography variants to fill out form fields realistically.

<Transformation
  template="Name: [mock.name]\nEmail: [mock.email]\nCity: [mock.city]"

## Technical Constraints

- **English Locale**: The `mock` namespace uses the `en` (English) locale for all generated data.
- **Synchronous Resolution**: Data is generated instantly during the interpolation phase without requiring external network calls.
- **Randomization**: Each call to a `mock` variable produces a new random value.
