The `lorem` system variable generates placeholder text.

### Syntax & Parameters

```text
[lorem(type=paragraphs, count=1)]
```

- **`type`**: Target text unit (`paragraphs`, `sentences`, `words`). Default is `paragraphs`.
- **`count`**: Number of units to generate. Default defaults: 15 for `words`, 1 for `sentences`, 1 for `paragraphs`.

### Single-Argument Auto-Detection

Passing a single bare number auto-detects as `count` (e.g., `[lorem(3)]` generates 3 paragraphs).

### Examples

| Expression | Description |
|---|---|
| `[lorem]` | Default 1 paragraph of placeholder text |
| `[lorem(3)]` | Single-arg numeric count $\rightarrow$ 3 paragraphs |
| `[lorem(words, 5)]` | 5 words of placeholder text |
| `[lorem(type=sentences, count=2)]` | Named parameter syntax |
