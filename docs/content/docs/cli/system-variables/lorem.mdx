The `[lorem]` namespace allows you to quickly generate placeholder text directly within your templates. This is perfect for mockups, testing layout constraints, or filling out forms during trigger development.

Bare `[lorem]` defaults to 1 paragraph (`[lorem.paragraph]`).

## Available Variants

| Variable | Description | Default | Example Output |
| :--- | :--- | :--- | :--- |
| `[lorem]` or `[lorem(n)]` | Generates paragraphs of placeholder text. | `1` | `(Paragraph separated by \n\n)` |
| `[lorem.word]` or `[lorem.word(n)]` | Generates words (default 15). | `15` | `consectetur adipiscing elit` |
| `[lorem.sentence]` or `[lorem.sentence(n)]` | Generates sentences (default 1). | `1` | `Sed do eiusmod tempor incididunt.` |
| `[lorem.paragraph]` or `[lorem.paragraph(n)]` | Generates paragraphs (default 1). | `1` | `(Multiple paragraphs separated by \n\n)` |

## Usage Details

### Numeric Arguments
All `lorem` variants accept an optional numeric argument `n` to control the amount of text generated. If omitted, Taurine falls back to sensible defaults (`1` paragraph, `15` words, or `1` sentence).

```text
[lorem] -> 1 paragraph
[lorem(3)] -> 3 paragraphs
[lorem.word] -> 15 words
[lorem.word(3)] -> "lorem ipsum dolor"
[lorem.sentence] -> 1 sentence
[lorem.sentence(2)] -> "Lorem ipsum dolor sit amet. Consectetur adipiscing elit."
```

### Dynamic Count
The `lorem` namespace supports Taurine's [Dynamic Variables](/docs/cli/dynamic-variables/nested-placeholders) feature. You can pass nested tags or variables to control the generation count dynamically.

```text
[lorem.word([count=10])]
[lorem.sentence([random.int(1, 3)])]
```

### Transformer Chaining
You can chain [format modifiers](/docs/cli/dynamic-variables/transformers) after the closing parenthesis to transform the generated text.

```text
[lorem.word(3) | upper] -> "LOREM IPSUM DOLOR"
[lorem.sentence(1) | title] -> "Lorem Ipsum Dolor Sit Amet."
```

## Examples

### Placeholder Content
Quickly fill out a field with a sentence of placeholder text.

<Transformation
  template="Comment: [lorem.sentence(1)]"
  input="mock "
  result="Comment: Pellentesque habitant morbi tristique senectus et netus."
/>

### Multiline Mocking
For larger content blocks like email bodies or documentation drafts, use `[lorem.paragraph(n)]`.

```text
Subject: Weekly Update
Hi Team,

[lorem.paragraph(2)]

Best,
Taurine
```

## Technical Constraints

- **Synchronous Resolution**: Like the `random` namespace, `lorem` variables resolve instantly without blocking the trigger pipeline.
- **English Locale**: The placeholder text currently uses the standard Latin-derived English locale for generation.
- **Formatting**: Words and sentences are joined by a single space, while paragraphs are separated by a double newline (`\n\n`).
