---
title: Lorem Placeholder Generators
description: Generate placeholder text in words, sentences, or paragraphs.
---

The `[lorem.*]` system variable suite generates lorem ipsum placeholder text.

## Available Variables

| Variable | Description | Default Count |
| :--- | :--- | :--- |
| `[lorem]` | Generates lorem ipsum text (paragraph mode). | 1 paragraph |
| `[lorem.words(n)]` | Generates `n` lorem ipsum words. | 15 words |
| `[lorem.sentences(n)]` | Generates `n` lorem ipsum sentences. | 1 sentence |
| `[lorem.paragraphs(n)]` | Generates `n` lorem ipsum paragraphs. | 1 paragraph |

## Examples

```text
[lorem.words(5)]
[lorem.sentences(3)]
[lorem.paragraphs(2)]
```
