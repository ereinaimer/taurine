Taurine provides a comprehensive suite of **System Variables** that allow you to inject dynamic data, execute shell commands, and control your machine directly from any trigger template.

Every system variable uses a unified `namespace(args)` call syntax with hybrid positional and named arguments.

## Syntax Rules

To ensure consistency and prevent collisions, Taurine enforces the following rules for system variables:

- **Unified Call Syntax**: All system variables use `[namespace(args)]` syntax (or bare `[namespace]` as `()` sugar). Dotted namespaces (e.g. `date.utc`) are save-time errors that suggest canonical syntax.
- **Hybrid Arguments**: Positionals are listed first, followed by `name=value` keyword parameters (e.g. `[execute(python, /s.py, file=true)]`). Positional arguments after named arguments are rejected.
- **Case Insensitivity**: Root namespaces and boolean keyword values (`true`/`false`) are case-insensitive.
- **Transformer Chaining**: You can chain [transformers](/docs/cli/reference/system-variable-modifiers) using pipe syntax. For example, `[clip | case(upper)]` or `[env(USER) | case(pascal)]`.
