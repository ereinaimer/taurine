Taurine provides a comprehensive suite of **System Variables** that allow you to inject dynamic data and control your machine without writing complex shell scripts. 

These variables are divided into two categories: **Content Variables** (which inject text like the date or clipboard) and **Directives** (which perform actions like pressing keys or moving the cursor).
