Taurine provides a comprehensive suite of **System Variables** that allow you to inject dynamic data, execute shell commands, and control your machine directly from any automation template.

These variables are divided into two categories: **Content Variables** (which inject text like the date, clipboard, or command output) and **Directives** (which perform actions like pressing keys or moving the cursor).

## Syntax Rules

To ensure future compatibility and prevent collisions with built-in features, Taurine enforces the following naming rules for variables:

- **Reserved Dot-Namespaces**: Any variable name containing a dot (`.`) is reserved for system use. You cannot create a custom variable named `user.name`; instead, use `user_name`.
- **Case Insensitivity**: System variable roots and modifiers are case-insensitive. `[TIME.UTC]` and `[time.utc]` will produce the same result.
- **Transformer Chaining**: You can chain [transformers](/docs/cli/reference/system-variable-modifiers) to any system variable using pipe syntax. For example, `[clip | upper]` or `[env(USER) | pascal]`.
