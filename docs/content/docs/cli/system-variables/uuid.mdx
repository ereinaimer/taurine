---
title: UUID Generator
description: Generate unique v4 and v7 identifiers.
---

The `uuid` system variable generates Universally Unique Identifiers (UUIDs).

### Syntax & Parameters

```text
[uuid(version=v4)]
```

- **`version`**: UUID version. Accepted values: `v4` (random, default), `v7` (time-ordered).

> [!NOTE]
> Bare numbers like `4` or `7` are rejected with a save-time diagnostic directing to `v4` or `v7`.

### Examples

| Expression | Description |
|---|---|
| `[uuid]` | Default random UUID v4 |
| `[uuid(v4)]` | Explicit UUID v4 |
| `[uuid(v7)]` | Time-ordered UUID v7 |
| `[uuid(version=v7)]` | Named parameter syntax |
