---
title: Shell Execution
description: Execute bash, PowerShell, Python, Node, and CMD scripts inside your snippet expansions.
---

The `execute` system variable allows you to execute shell scripts inline or silently in the background during snippet expansion.

### Syntax & Parameters

```text
[execute(lang, subject, *args, file=false, silent=false)]
```

- **`lang`** (required): Interpreter language (`bash`, `powershell`, `python`, `node`, `cmd`).
- **`subject`** (required): Command string or file path (if `file=true`).
- **`*args`**: Optional positional arguments passed to the script.
- **`file`**: Boolean flag (`true`/`false`). If `true`, `subject` is treated as a script file path. Keyword-only.
- **`silent`**: Boolean flag (`true`/`false`). If `true`, executes asynchronously in the background. Keyword-only.

### Examples

| Expression | Description |
|---|---|
| `[execute(bash, "echo hi")]` | Positional lang and inline command |
| `[execute(python, /s.py, a, b, file=true)]` | Script file execution with arguments |
| `[execute(bash, "sleep 5", silent=true)]` | Asynchronous silent background execution |
| `[execute(powershell, "Get-Date", silent=false)]` | Named keyword flag parameter |
