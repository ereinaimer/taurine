---
title: Time
description: Using time system variables in Taurine.
---

The `[time]` system variable allows you to insert the current time. Like `[date]`, it uses a zero-property, method-based API that lets you modify the context, perform calculations, and format the output using standard LDML tokens.

By default, `[time]` outputs the current local time in `HH:mm` (24-hour) format.

## Methods

You can chain methods onto `[time]` to customize the output.

| Method | Description | Example |
| :--- | :--- | :--- |
| `.utc` | Switches the time context to UTC instead of local time. | `[time.utc]` |
| `.calc(±...<units>)` | Adds or subtracts time. Requires a `+` or `-` sign. | `[time.calc(-30m)]` |
| `.format(<pattern>)` | Formats the time using LDML tokens. | `[time.format(hh:mm A)]` |

### Method Chaining

Methods are evaluated from left to right.
```text
[time.utc.calc(-5h).format(HH:mm:ss)]
```

## Time Formatting

Use the `.format()` method to format the time.

### LDML Tokens

| Token | Description | Example Output |
| :--- | :--- | :--- |
| `HH` | 24-hour hour, 2 digits | `14` |
| `H` | 24-hour hour, 1 or 2 digits | `14` |
| `hh` | 12-hour hour, 2 digits | `02` |
| `h` | 12-hour hour, 1 or 2 digits | `2` |
| `mm` | Minutes, 2 digits | `05` |
| `m` | Minutes, 1 or 2 digits | `5` |
| `ss` | Seconds, 2 digits | `09` |
| `s` | Seconds, 1 or 2 digits | `9` |
| `A` | AM/PM (uppercase) | `PM` |
| `a` | am/pm (lowercase) | `pm` |
| `Z` | Timezone offset | `+05:30` |
| `X` | Unix timestamp (seconds) | `1713709845` |
| `x` | Unix timestamp (millis) | `1713709845000` |

*Note: Date-related tokens (like `YYYY`, `MM`) cannot be used in `time.format()`.*

### Literal Text Escaping

To include literal text inside your format string without it being interpreted as a token, wrap the text in single quotes (`'...'`).

```text
[time.format('The current time is' hh:mm A)]
```
*Output: The current time is 02:30 PM*

## Time Calculations

Use the `.calc()` method to calculate relative times. You **must** provide a leading `+` or `-` sign, followed by amounts and unit characters. You can combine multiple units.

### Supported Time Units

| Unit | Description |
| :--- | :--- |
| `h` / `H` | Hours |
| `m` | Minutes |
| `s` / `S` | Seconds |

*Note: Date-related units (like `d`, `w`) cannot be used in `time.calc()`.*

### Examples

- `[time.calc(+30m)]` (30 minutes from now)
- `[time.calc(-1h15m)]` (1 hour and 15 minutes ago)
