---
title: Time
description: Using time-based system variables in Taurine.
---

The `[time.*]` namespace provides access to the current system time in various formats, as well as contextual strings like greetings.

## Reference Table

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[time.now]` | Current time (HH:mm) | `14:30` |
| `[time.full]` | Current time with seconds (HH:mm:ss) | `14:30:45` |
| `[time.greeting]` | Contextual greeting based on hour | `Good afternoon` |
| `[time.utc]` | Current UTC time (HH:mm) | `09:00` |
| `[time.tz]` | Current local timezone offset | `+05:30` |
| `[time.unix]` / `[time.epoch]` | Unix timestamp (seconds) | `1713709845` |
| `[time.millis]` / `[time.ms]` | Unix timestamp (milliseconds) | `1713709845000` |

<Callout title="Precision Note" type="info">
  By default, `now` and `utc` hide seconds for a cleaner look. If you need exact second-precision, always use the `full` variants or append the `.24h` modifier.
</Callout>

## Formatting Modifiers

You can specifically request 12-hour or 24-hour formats by appending `.12h` or `.24h` to time variables.

- `[time.now.12h]`: `02:30 PM`
- `[time.full.12h]`: `02:30:45 PM`
- `[time.hour.12h]`: `02`
- `[time.now.24h]`: `14:30`

## Component Variables

Extract specific parts of the current time.

| Variable | Description | Example Output |
| :--- | :--- | :--- |
| `[time.hour]` | 2-digit hour (24h default) | `14` |
| `[time.minute]` | 2-digit minute (00-59) | `30` |
| `[time.second]` | 2-digit second (00-59) | `45` |
| `[time.am_pm]` | Meridian indicator (AM/PM) | `PM` |

## Examples

### Dynamic Greeting
Use `[time.greeting]` to make your snippets feel more personal.

```text
[time.greeting], Erein! How can I help you today?
```

### Timestamps
Combine time with [transformers](/docs/cli/dynamic-variables/transformers) for log-ready formats.

<Transformation
  template="LOG [[time.full]]: Starting process..."
  input=">log "
  result="LOG [14:30:45]: Starting process..."
/>
