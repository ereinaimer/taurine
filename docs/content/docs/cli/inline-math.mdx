Taurine features a built-in mathematical engine that lets you use any text field as a quick calculator. Simply type a mathematical expression and press **Space**. 

It is **fully BEDMAS compatible**, meaning it follows the standard order of operations: Brackets, Exponents, Division and Multiplication, Addition and Subtraction.

<Callout title="Snippet Priority" type="info">
  Taurine only evaluates math expressions after checking your snippets. If your input matches an existing snippet trigger, that snippet will expand instead.
</Callout>

## Basic Operators

Taurine supports all standard arithmetic operators, including modulo and exponentiation.

| Operator | Description | Example | Result |
| :--- | :--- | :--- | :--- |
| `+` | Addition | `>2+3 ` | `5` |
| `-` | Subtraction | `>10-4 ` | `6` |
| `*` | Multiplication | `>3*4 ` | `12` |
| `/` | Division | `>10/2 ` | `5` |
| `%` | Modulo (Remainder) | `>10%3 ` | `1` |
| `^` | Exponentiation (Power) | `>2^3 ` | `8` |

Parentheses `()` can be used to group expressions and control the order of operations: `>(2+3)*4 ` expands to `20`.

## Constants

Taurine includes two of the most common mathematical constants. These are case-insensitive.

| Constant | Description | Value (Approx) |
| :--- | :--- | :--- |
| `pi` | Pi (Ratio of a circle's circumference to its diameter) | `3.1416` |
| `e` | Euler's Number | `2.7183` |

## Advanced Syntax

Taurine's parser is designed to feel natural, supporting features commonly found in scientific calculators.

### Implicit Multiplication
You don't always need the `*` operator. Taurine automatically inserts it in clear contexts:
- `>2(3+4) ` → `14`
- `>3pi ` → `9.4248`
- `>5sqrt(4) ` → `10`

### Scientific Notation
For very large or very small numbers, you can use standard scientific notation:
- `>1.5e3 ` → `1500`
- `>1e-2 ` → `0.01`

## Built-in Functions

Taurine provides several essential functions for common numeric manipulations.

| Function | Description | Example | Result |
| :--- | :--- | :--- | :--- |
| `sqrt(x)` | Square root | `>sqrt(16) ` | `4` |
| `abs(x)` | Absolute value | `>abs(-5) ` | `5` |
| `floor(x)` | Round down to nearest integer | `>floor(4.9) ` | `4` |
| `ceil(x)` | Round up to nearest integer | `>ceil(4.1) ` | `5` |
| `round(x)` | Round to nearest integer | `>round(4.5) ` | `5` |

## Technical Notes

- **Precision**: Results are automatically formatted to a maximum of **4 decimal places**. Trailing zeros and unnecessary decimal points are automatically trimmed.
- **Trigger Condition**: For an expression to be treated as math, it must contain at least one digit or a constant (`pi` or `e`).
- **Right Associativity**: Exponentiation is right-associative, meaning `2^3^2` is evaluated as `2^(3^2)`.
