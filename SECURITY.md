# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

We take security seriously from day one. If you discover a vulnerability in any current `1.x` release or the `main` branch, we highly encourage you to report it so it can be addressed immediately.

## Reporting a Vulnerability

We take the security of Taurine seriously. If you discover a security vulnerability, we'd appreciate it if you could bring it to our attention privately so we can evaluate and address it.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them by creating a [Private Vulnerability Report](https://github.com/ereinaimer/taurine/security/advisories/new) in this repository.

Please include the following information in your report if possible:

* Type of vulnerability 
* A clear description of the vulnerability and its potential impact
* Step-by-step instructions to reproduce the issue
* Any proposed solutions or mitigations (optional)

We will try our best to respond to your report within 48-72 hours and keep you informed of our progress towards a fix. Once the issue is resolved, we will publish a security advisory and credit you for the discovery (if desired).
